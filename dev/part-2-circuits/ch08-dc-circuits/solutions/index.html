    Node numbers start at 0 and branch \(k\) runs from fr[k] to to[k]; a positive branch current flows that way. The lab network is the one of the Chapter 2 lab: branches \((0,1)\), \((0,2)\), \((1,2)\), \((1,3)\), \((2,4)\), \((3,4)\), \((4,5)\) with conductances \(10, 5, 8, 4, 6, 3, 2\) S.

    Lab¶

    1. nodal_solve. The incidence matrix \(A\) has one row per branch with \(+1\) in the fr column and \(-1\) in the to column; \(A^\top \operatorname{diag}(g) A\) is the weighted Laplacian of the network, singular because its rows sum to zero. Deleting the ground row and column leaves the invertible \(G\) of the chapter; the solver fills the ground voltage with 0 and returns \(g \odot (Av)\) as branch currents. The injection given for the ground node is not used: ground supplies whatever balances the others. On the worked example it returns \(v = (0, 1.2857, 0.4286)\) V \(= (0, 18/14, 6/14)\) and the branch currents \(1.2857\) A through the 1 S branch and \(1.7143\) A through the 2 S and 4 S branches, which add up to the 3 A of the source.

      nodal.py: nodal_solve
      def incidence(fr, to, n: int) -> np.ndarray:
    """Branch-node incidence matrix A (branches × nodes): +1 at the from node, −1 at the to node."""
    a = np.zeros((len(fr), n))
    a[np.arange(len(fr)), fr] = 1.0
    a[np.arange(len(fr)), to] = -1.0
    return a


def nodal_solve(fr, to, g, inj, n: int, ground: int = 0) -> tuple[np.ndarray, np.ndarray]:
    """Node voltages and branch currents of a resistive network with current injections.

    Builds A and G = Aᵀ diag(g) A, deletes the ground row and column, solves G_r v_r = i_r and returns the
    full voltage vector (0 at ``ground``) with the branch currents g ⊙ (A v), positive from ``fr`` to ``to``.
    The injection at the ground node is ignored: ground supplies whatever balances the others.
    """
    a = incidence(fr, to, n)
    gmat = a.T @ np.diag(g) @ a
    keep = [k for k in range(n) if k != ground]
    v = np.zeros(n)
    v[keep] = np.linalg.solve(gmat[np.ix_(keep, keep)], np.asarray(inj, float)[keep])
    return v, np.asarray(g) * (a @ v)

    2. The Chapter 2 network. With \(0.5\) A into node 2, \(1\) A out of node 5 and node 0 grounded, the voltages are \(v = (0, -0.03041, -0.03918, -0.08889, -0.16686, -0.66686)\) V and the branch currents, in branch order, \((0.30409, 0.19591, 0.07018, 0.23392, 0.76608, 0.23392, 1.00000)\) A. KCL: \(A^\top i\) equals the injection at every node to \(10^{-12}\) once the ground injection is written as the \(+0.5\) A it must supply (the two branches leaving node 0 carry \(0.30409 + 0.19591 = 0.5\) A). Power balance: the sources deliver \(v^\top i = 0.5\,(0) + 0.5\,(-0.03918) - 1\,(-0.66686) = 0.647271\) W and the branches dissipate \(\sum_k g_k (Av)_k^2 = \sum_k i_k^2 / g_k = 0.647271\) W, the same number (Exercise 3 proves it must be).

    3. Superposition. Solving with the \(0.5\) A alone and with the \(-1\) A alone and adding the two voltage vectors reproduces the voltages of step 2 to \(3\cdot10^{-17}\) (superposition_check). The solution map \(i \mapsto v = G^{-1} i\) is linear, so it respects sums; this is the property that lets Chapter 17 build flows from one sensitivity per injection and add them.

    4. Thévenin. Injecting 1 A at node 5 and withdrawing it at node 0 gives \(v_5 - v_0 = 0.71189\ \Omega\) (thevenin_resistance, one linear solve: the second solve of the chapter's "two linear solves" is only needed when the open-circuit voltage is wanted too). The Chapter 3 effective resistance \((e_5 - e_0)^\top L^+ (e_5 - e_0)\) with the pseudoinverse of the full Laplacian is \(0.71189\ \Omega\) too, to \(10^{-12}\): they are the same quantity. Sanity check: node 5 hangs off node 4 through the single 2 S branch (\(0.5\ \Omega\)), so the Thévenin resistance must exceed \(0.5\ \Omega\); the rest of the network between node 4 and ground adds \(0.21189\ \Omega\).

      nodal.py: Thévenin and effective resistance
      def thevenin_resistance(fr, to, g, n: int, a: int, b: int) -> float:
    """Thévenin (effective) resistance between nodes a and b: inject 1 A at a, withdraw it at b, read v_a − v_b."""
    inj = np.zeros(n)
    inj[a], inj[b] = 1.0, -1.0
    v, _ = nodal_solve(fr, to, g, inj, n, ground=b)
    return float(v[a] - v[b])


def effective_resistance(fr, to, g, n: int, a: int, b: int) -> float:
    """The Chapter 3 formula (e_a − e_b)ᵀ L⁺ (e_a − e_b) with the pseudoinverse of the full Laplacian."""
    amat = incidence(fr, to, n)
    lap = amat.T @ np.diag(g) @ amat
    e = np.zeros(n)
    e[a], e[b] = 1.0, -1.0
    return float(e @ np.linalg.pinv(lap) @ e)

    5. Split a node. split_node_2 moves branch \((2, 4)\) to a new node 6 (busbar B), keeps \((0, 2)\), \((1, 2)\) and the \(0.5\) A on node 2 (busbar A) and adds the coupler branch \((2, 6)\) with \(10^6\) S. The coupler current is \(0.76608\) A from A to B, across a drop of \(7.7\cdot10^{-7}\) V. From the unsplit solution, the imbalance at A is the flow into A over its two branches plus the injection at A: \(0.19591 + 0.07018 + 0.5 = 0.76608\) A, and the two agree to \(10^{-6}\). They must: in the unsplit network KCL at node 2 says that whatever enters through \((0, 2)\), \((1, 2)\) and the source leaves through \((2, 4)\), and after the split the only way from A to \((2, 4)\) is the coupler. When the coupler is ideal (zero voltage drop) the split network has the same voltages as the unsplit one, so every other current is unchanged and the coupler simply makes the hidden internal current of node 2 visible. This is the number ToOp computes in _compute_bus_a_imbalance (Exercise 6).

      nodal.py: split_node_2
      def split_node_2(coupler_g: float = 1e6) -> dict[str, float]:
    """Split node 2 of the lab network into busbar A (branches (0, 2), (1, 2), the 0.5 A) and busbar B (branch (2, 4)).

    Busbar B is a new node 6; a coupler branch (2, 6) of conductance ``coupler_g`` joins them. Returns the coupler
    current (A to B), the KCL imbalance at A computed from the unsplit solution (flows into A over its branches
    plus the injection at A) and the voltage across the coupler.
    """
    fr, to, g = [*FR, 2], [*TO, 6], [*G, coupler_g]
    fr[FR.index(2)] = 6  # branch (2, 4) now leaves busbar B
    inj = [*INJ, 0.0]
    v, i = nodal_solve(fr, to, g, inj, N + 1)
    _, i0 = nodal_solve(FR, TO, G, INJ, N)
    into_a = sum(i0[k] for k in range(len(FR)) if TO[k] == 2)  # branches (0, 2) and (1, 2) end at A
    return {'coupler': float(i[-1]), 'imbalance_a': float(into_a + INJ[2]), 'coupler_volts': float(v[2] - v[6])}

    Exercise 1¶

    Number the nodes 0 (bottom, ground), 1 (top), 2 (left) and 3 (right); \(R_1\) joins 1–2, \(R_2\) joins 1–3, \(R_3\) joins 2–0, \(R_4\) joins 3–0 and \(R_5\) is the middle branch 2–3; the source pushes \(I\) into node 1 and takes it from node 0. With \(g_k = 1/R_k\), KCL at the three ungrounded nodes reads

    \[ \begin{bmatrix} g_1 + g_2 & -g_1 & -g_2 \\ -g_1 & g_1 + g_3 + g_5 & -g_5 \\ -g_2 & -g_5 & g_2 + g_4 + g_5 \end{bmatrix} \begin{bmatrix} v_1 \\ v_2 \\ v_3 \end{bmatrix} = \begin{bmatrix} I \\ 0 \\ 0 \end{bmatrix}. \]

    The middle current is \(g_5 (v_2 - v_3)\), zero exactly when \(v_2 = v_3\). Put \(v_2 = v_3 = w\) in the second and third equations: the \(g_5\) terms cancel and they become \(g_1 v_1 = (g_1 + g_3)\, w\) and \(g_2 v_1 = (g_2 + g_4)\, w\), which are compatible only if \(g_1 (g_2 + g_4) = g_2 (g_1 + g_3)\), that is \(g_1 g_4 = g_2 g_3\), or in resistances

    \[ R_1 R_4 = R_2 R_3 \qquad \Big(\tfrac{R_1}{R_3} = \tfrac{R_2}{R_4}\Big). \]

    Both arms then divide \(v_1\) in the same ratio, \(w = v_1 R_3/(R_1 + R_3) = v_1 R_4/(R_2 + R_4)\), and the condition does not involve \(R_5\) or \(I\): a balanced bridge stays balanced for any middle resistor and any source. Numeric check with bridge_currents: \(R = (100, 200, 50, 100, 1000)\ \Omega\) satisfies \(R_1 R_4 = R_2 R_3 = 10^4\) and gives \(v_2 - v_3 = 0\) and a middle current of \(0\) to \(10^{-12}\); changing \(R_4\) to \(120\ \Omega\) gives \(v_2 - v_3 = -3.839\) V and \(-3.839\) mA through the middle branch.

    wheatstone.py: bridge
    def bridge_currents(r: list[float], i_src: float = 1.0) -> tuple[np.ndarray, np.ndarray]:
    """Node voltages and branch currents (R1, R2, R3, R4, R5 order) of the bridge fed by ``i_src`` at node 1."""
    g = 1 / np.asarray(r, float)
    return nodal_solve(BRIDGE_FR, BRIDGE_TO, g, [-i_src, i_src, 0.0, 0.0], 4)


def is_balanced(r: list[float]) -> bool:
    """R1 R4 = R2 R3, the condition for zero current in the middle branch."""
    r1, r2, r3, r4, _ = r
    return bool(np.isclose(r1 * r4, r2 * r3))

    Exercise 2¶

    Resistances \(R_a = 1\ \Omega\) (node 1 to ground), \(R_b = 1/2\ \Omega\) (nodes 1–2), \(R_c = 1/4\ \Omega\) (node 2 to ground). Take mesh 1 as the loop of the current source and \(R_a\), and mesh 2 as the loop \(R_a\)–\(R_b\)–\(R_c\), both clockwise. The source fixes \(I_1 = 3\) A; KVL around mesh 2, \(R_a (I_2 - I_1) + R_b I_2 + R_c I_2 = 0\), gives \(I_2 = R_a I_1 / (R_a + R_b + R_c) = 3 / 1.75 = 12/7 = 1.7143\) A. Then \(v_1 = R_a (I_1 - I_2) = 9/7 = 1.2857\) V and \(v_2 = R_c I_2 = 3/7 = 0.4286\) V, the voltages of the worked example (\(18/14\) and \(6/14\)). The mesh currents are the branch currents of step 1: \(I_1 - I_2 = 1.2857\) A in the 1 S branch and \(I_2 = 1.7143\) A in the series pair. In Octave mesh_nodal solves \(G v = i\) and the mesh system \(R\, I = (I_s, 0)\) and returns both; the Octave test block checks that they agree to \(10^{-12}\). Nodal analysis needs one equation per ungrounded node (2), mesh analysis one per independent loop (2 here, with one trivial because of the current source); for grids with thousands of buses and a current-source model of injections the nodal form wins, which is why power flow is nodal.

    mesh_nodal.m
    function [v_nodal, v_mesh, i_mesh] = mesh_nodal()
  % The worked example of Chapter 8 solved twice: by nodal analysis (G v = i) and by mesh analysis.
  % Conductances 1 S (node 1 to ground), 2 S (nodes 1-2), 4 S (node 2 to ground); a 3 A source feeds node 1.
  % Mesh 1 holds the source and the 1 ohm resistor, so I1 = 3 A; mesh 2 runs through the 1, 1/2 and 1/4 ohm
  % resistors: KVL gives Ra (I2 - I1) + (Rb + Rc) I2 = 0.
  G = [1 + 2, -2; -2, 2 + 4];
  v_nodal = G \ [3; 0];
  Ra = 1; Rb = 1 / 2; Rc = 1 / 4; Is = 3;
  R = [1, 0; -Ra, Ra + Rb + Rc];
  i_mesh = R \ [Is; 0];
  v_mesh = [Ra * (i_mesh(1) - i_mesh(2)); Rc * i_mesh(2)];
end

    Exercise 3¶

    \(u^\top j = (Av)^\top j = v^\top (A^\top j) = v^\top i\): two lines, using only \(u = Av\) (KVL, the branch voltages are differences of node potentials) and \(A^\top j = i\) (KCL). Nothing relates \(u\) to \(j\): they may come from different circuits on the same graph, and the theorem still holds. For the power balance take \(j = i_\text{branch} = \operatorname{diag}(g)\, Av\) of the same network: \(u^\top j = (Av)^\top \operatorname{diag}(g)\, (Av) = \sum_k g_k (Av)_k^2\), the Joule power, while \(v^\top i\) is the power delivered by the sources (ground included, at potential 0). So \(\sum_k g_k (Av)_k^2 = v^\top i\), which is lab step 2. tellegen_check runs the stronger statement: the voltages of the lab network (\(g = 10, 5, 8, 4, 6, 3, 2\) S) and the currents of a unit-conductance network with the same injections give \(u^\top j = 0.647271\) W \(= v^\top i\); with random conductances for the second network the two sides still agree to \(10^{-12}\).

    wheatstone.py: tellegen_check
    def tellegen_check(fr, to, g, inj, n: int, g_other) -> tuple[float, float]:
    """uᵀ j against vᵀ i, with u = A v from the network ``g`` and j the branch currents of a network ``g_other``.

    Both networks share the graph and the injections, so j satisfies Aᵀ j = i although it belongs to another
    circuit; Tellegen's theorem says the two numbers agree anyway.
    """
    v, _ = nodal_solve(fr, to, g, inj, n)
    _, j = nodal_solve(fr, to, g_other, inj, n)
    u = incidence(fr, to, n) @ v
    return float(u @ j), float(v @ np.asarray(inj, float))

    Exercise 4¶

    Let \(L = A^\top \operatorname{diag}(g) A\) be the full Laplacian and \(i\) a balanced injection vector (\(\mathbf 1^\top i = 0\), the ground node's share included). Grounding node \(r\) means solving \(Lv = i\) with \(v_r = 0\); grounding node \(s\) means solving the same \(Lv' = i\) with \(v'_s = 0\). The null space of \(L\) of a connected network is spanned by \(\mathbf 1\) (Chapter 2), so every solution of \(Lv = i\) is \(v + c\mathbf 1\) for one constant \(c\): \(v' = v - v_s \mathbf 1\). All voltages shift by the same constant and \(u = Av' = Av - v_s A\mathbf 1 = Av\) because each row of \(A\) sums to zero, so every branch current \(g \odot u\) is unchanged. Check with nodal_solve (ground 0, then 3): the voltages become \((0.08889, 0.05848, 0.04971, 0, -0.07797, -0.57797)\) V, each exactly \(0.08889\) V \(= -v_3\) above the ground-0 solution, and the branch currents agree to \(2\cdot10^{-16}\). The condition "balanced" matters: the solver ignores the injection at the ground node, so if the injections of the other nodes do not sum to the negative of the ground's, grounding another node changes the problem (a different node then supplies the balance) and the currents do change. That is why INJ in nodal.py lists the \(+0.5\) A of node 0.

    The KCL argument of lab step 5 assumes that A and B are at the same potential, so that the split network has the unsplit voltages and only the hidden internal current of node 2 becomes visible. A coupler of finite conductance \(g_c\) is a resistor in series with branch \((2, 4)\): the path from A to node 4 now has resistance \(1/6 + 1/g_c\) instead of \(1/6\ \Omega\), so less current takes it (\(0.684\) A at \(10\) S, where the coupler adds \(0.1\ \Omega\) to \(0.167\ \Omega\)) and more leaves A through \((0, 2)\) and \((1, 2)\); the potentials of every node move, and the "imbalance at A" of the unsplit solution no longer describes the coupler. At \(10^3\) S the extra \(1\) m\(\Omega\) is \(0.6\ \%\) of the path and the error is \(0.12\ \%\); at \(10^6\) S it is invisible. ToOp's update after a split (Chapter 18) uses the unsplit flows and the imbalance formula, which is exact only for a closed, ideal coupler: a closed coupler in a real substation is a busbar section with a negligible impedance, so the assumption holds; an open coupler is the opposite case (the two busbars become two buses with no flow between them), handled as a different topology, not as a weak coupler. split_node_2(coupler_g) prints the table.

    Exercise 6¶

    _compute_bus_a_imbalance in toop_engine_dc_solver/jax/cross_coupler_flow.py (ToOp commit ba1874e) computes, per timestep,

    imbalance_a = sum(flows[branch_to_a]) - sum(flows[branch_from_a]) + bus_a_injection

    and returns it as the cross-coupler flow, zeroing it when the substation index is out of range or when the configuration mask puts no branch on busbar A (jnp.all(~substation_configuration)). Term by term against lab step 5:

    ToOp Lab step 5
    flows (timesteps × branches, "potentially already updated by previous splits") the branch currents \(i = g \odot (Av)\) of the unsplit solution
    branch_to_a: branches whose flow direction is towards bus A branches \((0, 2)\) and \((1, 2)\), whose to end is node 2: \(0.19591 + 0.07018\) A
    branch_from_a: branches whose flow direction is away from bus A none here (branch \((2, 4)\) leaves from node 2 but is assigned to busbar B)
    bus_a_injection: net power injection assigned to bus A the \(0.5\) A kept on busbar A
    substation_configuration (True = branch on bus A) the choice \(\{(0, 2), (1, 2)\} \to\) A, \(\{(2, 4)\} \to\) B
    imbalance_a the coupler current \(0.76608\) A from A to B
    .get(mode='fill', fill_value=0.0) on padded indices substations have different numbers of branches; the padding entries contribute 0

    "Towards A" and "away from A" refer to the orientation of each branch (its fr/to convention), not to the sign of the flow, exactly as the lab sums signed currents \(i_k\) with the sign of \(A\). The function works in power (MW) where the lab works in amperes, and over many timesteps at once (the axis=1 sums), but the formula is the KCL of lab step 5 and nothing more: with the flows of the unsplit grid it is exact for a closed ideal coupler (Exercise 5), and Chapter 18 shows how this one number then updates every other flow.
