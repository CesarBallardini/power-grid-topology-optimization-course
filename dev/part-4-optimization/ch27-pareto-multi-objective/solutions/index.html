    Chapter 27 – Solutions¶

    Solutions of the Lab and the Exercises of Chapter 27. Try each task before reading its solution. The code is in the chapter's src folder: pareto.py (dominance, sorting, scalarizations, indicators), dominator_filter.py (a port of ToOp's dominator filter and its counterexamples), repertoire_cells.py (clipped cells and the non-dominated set of a repertoire table), augmecon.py (AUGMECON2 with PuLP and HiGHS) and ch27_ieee30.py (the exact bi-objective front of IEEE 30 line switching, a small NSGA-II and a small MAP-Elites). Each module prints the numbers quoted below when run as a script. The ports were checked against ToOp ba1874e with test_dominator_filter_toop.py (ToOp's interpreter, make test-toop). pymoo, moocore and QDax are not installed in the course environment, so every indicator and sorting routine is implemented in NumPy and tested against brute force; Lab 5 and Exercises 3 and 4 also run them in the labs container (docker/labs, make test-labs), with the *_labs.py modules. The ToOp results of Labs 1, 3, 4 and 7 come from fifteen DC runs that toop_front_toop.py made in the course's ToOp container (image toop-course:cpu, ToOp ba1874e) on the complex example grid data/complex_grid/grid.xiidm, each with 60 s of search and a CPU budget of docker run --cpus 4 (three containers ran side by side, so a run took 61 to 70 s of wall time and used about 1.2 cores). Their res.json files are in src/toop_front/ (about 13 KB each) and toop_front.py prints every number quoted from them.

    1. Pareto vs weighted-sum winner. The run fine_s1 uses ToOp's default repertoire (split_subs × switching_distance, 5 × 45 cells, at most 4 splits), the default fitness \(-\)overload_energy_n_1 and seed 1; it made 203 epochs in 60 s. toop_front.table('fine_s1') turns its best_topos into a table with the actions, fitness, the four metrics and the cell, and lab1 computes the non-dominated set of (overload_energy_n_1, switching_distance, split_subs, critical_branch_count_n_1), all minimized. The best-fitness elite, ToOp's max_fitness (actions [1, 54, 68, 118]: 1160.37 MW, switching distance 10, 4 splits, 31 critical branches) is dominated: [1, 54, 68] removes the same overload energy with 3 splits and switching distance 8.       toop_front.py (table and Lab 1)
      def table(name: str, runs: Path = RUNS) -> pd.DataFrame:
    """One row per elite of ``best_topos``: actions, fitness, the four metrics (rounded) and the (clipped) cell.

    ``fitness`` is kept as ToOp wrote it, so its maximum is ToOp's winner; the metrics are rounded to ``DECIMALS``
    so that two topologies with the same flows compare as equal in the dominance tests.
    """
    res = load(name, runs)
    shape = n_cells(res)
    rows = []
    for topo in res['best_topos']:
        scores = topo['metrics']['extra_scores']
        row = {'actions': topo['actions'], 'fitness': topo['metrics']['fitness']}
        row.update({m: round(scores[m], DECIMALS) for m in METRICS})
        descriptor = (int(scores['split_subs']), int(scores['switching_distance']))
        row['cell'] = cell_index(descriptor, shape)
        row['exact_cell'] = exact_cell_index(descriptor, shape)
        rows.append(row)
    return pd.DataFrame(rows)


def lab1(name: str = 'fine_s1') -> dict:

    t = table(name)
    nd = pareto.non_dominated_mask(t[METRICS].to_numpy(float))
    best = int(t['fitness'].idxmax())
    clipped = t['exact_cell'].isna().to_numpy()
    return {
        'elites': len(t),
        'non_dominated': int(nd.sum()),
        'dominated': int((~nd).sum()),
        'best': best,
        'best_non_dominated': bool(nd[best]),
        'edge_elites': int(clipped.sum()),
        'edge_elites_dominated': int((clipped & ~nd).sum()),
        'mask': nd,
    }

def synthetic_repertoire(seed: int = 27, n: int = 60) -> pd.DataFrame:
    """A made-up repertoire table in the shape ToOp writes, with one elite per cell and a weighted-sum fitness."""
    rng = np.random.default_rng(seed)
    split_subs = rng.integers(1, 8, n)
    switching_distance = split_subs * rng.integers(2, 12, n)
    overload = np.round(300 / (1 + split_subs) + rng.normal(0, 25, n).clip(-60, 60) + 30, 1)
    critical = np.maximum(0, (overload / 40 + rng.normal(0, 1.5, n)).round()).astype(int)
    df = pd.DataFrame(
        {
            'overload_energy_n_1': overload.clip(0),
            'switching_distance': switching_distance,
            'split_subs': split_subs,
            'critical_branch_count_n_1': critical,
        }
    )
    df['fitness'] = -(df['overload_energy_n_1'] + 10 * df['critical_branch_count_n_1'])
    df['cell'] = [cell_index(d) for d in df[['split_subs', 'switching_distance']].to_numpy()]
    return (
        df.sort_values('fitness', ascending=False).drop_duplicates('cell').sort_values('cell').reset_index(drop=True)
    )


def analyse(table: pd.DataFrame, n_cells: tuple[int, ...] = N_CELLS) -> dict:
    """Non-dominated rows, the best-fitness row, how many elites are dominated, and the edge-cell elites."""
    points = table[METRICS].to_numpy(float)
    nd = pareto.non_dominated_mask(points)
    exact = [exact_cell_index(d, n_cells) for d in table[['split_subs', 'switching_distance']].to_numpy()]
    clipped = np.array([c is None for c in exact])
    return {
        'non_dominated': np.flatnonzero(nd),
        'best_fitness': int(table['fitness'].idxmax()),
        'dominated_count': int((~nd).sum()),
        'edge_cell_elites': np.flatnonzero(clipped),  # with exactly-equal constraints they would have no cell
    }

    2. Test the dominator filter. dominator_mask ports get_dominator_mask line by line; the ToOp test runs the original on the same frames and the masks agree. Fitness is maximized, the observed metrics (switching_distance, disconnections) are minimized, the target metric is split_subs.

      (a) A non-dominated row that the filter removes:

      row fitness split_subs switching_distance disconnections dominator Pareto
      0 −1.0 1 3 0 kept non-dominated
      1 −2.0 1 2 1 removed non-dominated

      Row 1 has a lower fitness than the group best (row 0) and is worse in one observed metric (disconnections), which is all the filter checks (an OR across metrics); that it is better in switching_distance is never looked at, so a genuine trade-off disappears.

      (b) Dominated rows that the filter keeps:

      row fitness split_subs switching_distance disconnections dominator Pareto
      0 −1.0 1 5 0 kept non-dominated
      1 −3.0 1 5 0 kept dominated by row 0
      2 −2.0 1 1 0 kept non-dominated
      3 −2.5 1 2 0 kept dominated by row 2

      Row 1 has exactly the metrics of the best and a worse fitness: the filter asks for a strictly larger metric, so equality protects it. Row 3 is better than the best (row 0) in switching_distance, so the filter never removes it, although row 2, which is not the group best, beats it in fitness and in every metric. A Pareto filter compares every pair; the dominator filter compares each row with one row only.

      Order dependence: with target_metrics = [split_subs, switching_distance] and disconnections observed, the three rows of order_example() (fitness −1, −2, −3; split_subs 1, 1, 2; switching_distance 2, 3, 3; disconnections 0, 1, 2) give the mask [True, False, True]; with [switching_distance, split_subs] the mask is [True, False, False]. In the second order the pass over switching_distance = 3 finds row 1 still present, makes it the group best and removes row 2 (lower fitness, more disconnections); in the first order row 1 has already been removed by the split_subs pass, row 2 is alone in its group and survives. Row 2 is dominated by row 0 in both cases, so neither answer is "right": the filter is a heuristic whose output depends on the order of the configuration list.

      dominator_filter.py (the two filters)
      def dominator_mask(df: pd.DataFrame, target_metrics: list[str], observed_metrics: list[str]) -> np.ndarray:
    """Port of ToOp's ``get_dominator_mask``: True keeps the row.

    For each target metric, in order, and each of its discrete values: take the row with the best fitness among
    the rows of that value that are still kept, and remove every row of that value whose fitness is lower *and*
    which is larger in *any* observed metric.
    """
    removed = np.zeros(len(df), dtype=bool)
    for target in target_metrics:
        for value in df[target].unique():
            group = (df[target] == value).to_numpy()
            if not (group & ~removed).any():
                continue
            best = df.loc[group & ~removed, 'fitness'].idxmax()
            lower_fitness = (df['fitness'] < df.at[best, 'fitness']).to_numpy()
            for col in observed_metrics:
                if col == 'fitness':
                    continue
                removed |= (df[col] > df.at[best, col]).to_numpy() & lower_fitness & group
    return ~removed


def pareto_mask(df: pd.DataFrame, metrics: list[str]) -> np.ndarray:
    """True for the rows no other row dominates in (fitness maximized, every metric minimized)."""
    points = np.c_[-df['fitness'].to_numpy(float), df[metrics].to_numpy(float)]
    p, q = points[:, None, :], points[None, :, :]
    return ~(np.all(q <= p, axis=2) & np.any(q < p, axis=2)).any(axis=1)

      pareto.py (scalarizations)
      def weighted_sum_argmin(points: np.ndarray, weights: np.ndarray) -> np.ndarray:
    """Indices of every minimizer of the weighted sum (ties kept, within 1e-12)."""
    values = points @ weights
    return np.flatnonzero(values <= values.min() + 1e-12)


def weighted_sum_sweep(points: np.ndarray, n_weights: int = 1001) -> set[int]:
    """Indices that win the two-objective weighted sum for some weight (w, 1 - w) on a grid of ``n_weights`` values."""
    winners: set[int] = set()
    for w in np.linspace(0, 1, n_weights):
        winners.update(int(i) for i in weighted_sum_argmin(points, np.array([w, 1 - w])))
    return winners


def supported_mask(points: np.ndarray, tol: float = 1e-9) -> np.ndarray:
    """True for the non-dominated points that minimize some weighted sum with non-negative weights.

    For each point ``p`` an LP looks for weights on the simplex with ``w . (q - p) >= t`` for every other point
    ``q`` and the largest ``t``; ``p`` is supported when that ``t`` is not negative. Points inside a non-convex
    part of the front (unsupported) have ``t < 0`` for every weight.
    """
    n, m = points.shape
    supported = np.zeros(n, dtype=bool)
    nd = non_dominated_mask(points)
    for i in np.flatnonzero(nd):
        others = np.delete(points, i, axis=0) - points[i]
        # variables: w (m), t; maximize t  <=>  minimize -t
        c = np.r_[np.zeros(m), -1.0]
        a_ub = np.c_[-others, np.ones(len(others))]  # t - w.(q-p) <= 0
        a_eq = np.r_[np.ones(m), 0.0][None, :]
        bounds = [(0, None)] * m + [(None, None)]
        res = linprog(c, A_ub=a_ub, b_ub=np.zeros(len(others)), A_eq=a_eq, b_eq=[1.0], bounds=bounds, method='highs')
        supported[i] = res.success and -res.fun >= -tol
    return supported


def epsilon_constraint(points: np.ndarray, objective: int, bounds: np.ndarray) -> int | None:
    """Index of the point minimizing ``objective`` among those whose other objectives respect ``bounds``.

    Ties on the minimized objective are broken by the sum of the others, which removes the weakly efficient
    points that a plain epsilon-constraint can return (the slack term of AUGMECON plays the same role).
    """
    others = np.delete(np.arange(points.shape[1]), objective)
    feasible = np.flatnonzero(np.all(points[:, others] <= bounds[others] + 1e-12, axis=1))
    if feasible.size == 0:
        return None
    key = np.lexsort((points[feasible][:, others].sum(axis=1), points[feasible, objective]))
    return int(feasible[key[0]])


def achievement_scalarizing(points: np.ndarray, reference: np.ndarray, weights=None, rho: float = 1e-3) -> int:
    """Index minimizing the achievement scalarizing function max_i w_i (f_i - r_i) + rho sum_i w_i (f_i - r_i)."""
    w = np.ones(points.shape[1]) if weights is None else np.asarray(weights, dtype=float)
    d = w * (points - reference)
    return int(np.argmin(d.max(axis=1) + rho * d.sum(axis=1)))


def pseudo_weights(points: np.ndarray) -> np.ndarray:
    """Pseudo-weight vector of each point: (f_max - f_i) / (f_max - f_min), normalized to sum one per point."""
    lo, hi = points.min(axis=0), points.max(axis=0)
    span = np.where(hi > lo, hi - lo, 1.0)
    w = (hi - points) / span
    return w / w.sum(axis=1, keepdims=True)


def knee_points(points: np.ndarray) -> np.ndarray:
    """Indices of the two-objective front points farthest below the line through its two extreme points.

    A knee is where a small gain in one objective costs a large loss in the other. On a convex front the farthest
    point from the chord between the extremes is the usual knee estimate; every point within 1e-9 of that distance
    is returned.
    """
    order = np.argsort(points[:, 0])
    a, b = points[order[0]], points[order[-1]]
    direction = b - a
    normal = np.array([direction[1], -direction[0]])
    normal = normal / (np.linalg.norm(normal) or 1.0)
    distance = (points - a) @ normal
    distance = distance * np.sign(distance[np.abs(distance).argmax()] or 1.0)
    below = np.flatnonzero(distance >= distance.max() - 1e-9)
    return below if distance.max() > 1e-9 else np.array([], dtype=int)

      def n1_metrics(case: dict, switched_off: tuple[int, ...] = ()) -> tuple[float, int]:
    """N-1 overload energy (MW) and critical branch count of the network without ``switched_off``.

    The same post-contingency flows as ``ch27_ieee30.overload_energy`` (bridge outages left out); a branch is critical
    when its flow exceeds its rating in at least one outage. ``(inf, -1)`` when the network is islanded.
    """
    in_service = np.ones(len(case['lines']), dtype=bool)
    in_service[list(switched_off)] = False
    h = ieee30.ptdf(case, in_service)
    if h is None:
        return np.inf, -1
    lines, rating = case['lines'][in_service], case['rating'][in_service]
    f = h @ case['p']
    hk = h[:, lines[:, 0]] - h[:, lines[:, 1]]
    denominator = 1 - np.diag(hk)
    not_bridge = np.abs(denominator) > 1e-9
    post = f[:, None] + hk[:, not_bridge] / denominator[not_bridge] * f[not_bridge]
    post[np.flatnonzero(not_bridge), np.arange(not_bridge.sum())] = 0
    excess = np.maximum(0, np.abs(post) - rating[:, None])
    return float(excess.sum()), int(np.any(excess > 1e-9, axis=1).sum())


def build_table(case: dict, k_max: int = K_MAX) -> dict:
    """Objectives and descriptors of every switching of at most ``k_max`` lines, indexed by its sorted genotype.

    A genotype is ``k_max`` line indices sorted ascending and padded with the sentinel ``n_line`` (Chapter 24's
    encoding), so ``table['energy'][g0, g1, g2]`` is its overload energy. Returns the dense arrays, the list of
    feasible genotypes (not islanded) and the normalization of the objectives (their intact-network values).
    """
    n_line = len(case['lines'])
    shape = (n_line + 1,) * k_max
    energy, critical = np.full(shape, np.inf), np.full(shape, -1)
    descriptor = np.zeros((*shape, 2))
    feasible = []
    for k in range(k_max + 1):
        for subset in itertools.combinations(range(n_line), k):
            g = (*subset, *(n_line,) * (k_max - k))
            energy[g], critical[g] = n1_metrics(case, subset)
            descriptor[g] = (k, len(np.unique(case['lines'][list(subset)]))) if k else (0, 0)
            if np.isfinite(energy[g]):
                feasible.append(g)
    feasible = np.array(feasible)
    scale = np.array(n1_metrics(case), dtype=float)
    fitness = -np.stack([energy, critical], axis=-1) / scale  # QDax maximizes
    fitness[~np.isfinite(energy)] = -np.inf
    return {
        'n_line': n_line,
        'energy': energy,
        'critical': critical,
        'fitness': fitness,
        'descriptor': descriptor,
        'feasible': feasible,
        'scale': scale,
    }

      def make_scoring(table: dict):
    """JAX scoring function ``(genotypes, key) -> (fitnesses, descriptors, extra)``: a lookup in the table.

    The repertoire stores genotypes as floats (QDax fills empty slots with zeros of the default dtype), so the
    integer line indices are recovered by rounding and sorting before the lookup.
    """
    fitness, descriptor = jnp.asarray(table['fitness']), jnp.asarray(table['descriptor'])

    def scoring(genotypes, key):
        g = jnp.sort(jnp.round(genotypes).astype(jnp.int32), axis=1)
        index = tuple(g[:, i] for i in range(g.shape[1]))
        return fitness[index], descriptor[index], {}

    return scoring


def make_mutation(table: dict):
    """Chapter 24's mutation in JAX: one slot becomes the sentinel (p = 0.3) or a random line; duplicates removed.

    A child that islands the grid is replaced by its parent, so every genotype in the repertoire is feasible and its
    fitness finite (QDax marks empty slots with -inf).
    """
    n_line = table['n_line']
    feasible = jnp.asarray(np.isfinite(table['energy']))

    def mutate_one(genotype, key):
        k_slot, k_kind, k_line = jax.random.split(key, 3)
        g = jnp.round(genotype).astype(jnp.int32)
        slot = jax.random.randint(k_slot, (), 0, g.shape[0])
        value = jnp.where(jax.random.uniform(k_kind) < 0.3, n_line, jax.random.randint(k_line, (), 0, n_line))
        child = jnp.sort(g.at[slot].set(value))
        duplicate = jnp.concatenate([jnp.array([False]), child[1:] == child[:-1]])
        child = jnp.sort(jnp.where(duplicate, n_line, child))
        ok = feasible[tuple(child[i] for i in range(child.shape[0]))]
        return jnp.where(ok, child, g).astype(genotype.dtype)

    def mutation(genotypes, key):
        return jax.vmap(mutate_one)(genotypes, jax.random.split(key, genotypes.shape[0]))

    return mutation

    """Branch list, ratings and net injections of IEEE 30 with loads and generation scaled by ``scale``.

    Returns a dict with ``lines`` (from, to) zero-based, ``x`` (p.u. reactance), ``rating`` (MW), ``p`` (net injection

    x = (net.line.x_ohm_per_km * net.line.length_km / z_base).to_numpy()
    rating = (np.sqrt(3) * net.bus.vn_kv.iloc[0] * net.line.max_i_ka).to_numpy()
    p = np.zeros(len(net.bus))
    np.add.at(p, net.gen.bus.to_numpy(), scale * net.gen.p_mw.to_numpy())
    np.add.at(p, net.load.bus.to_numpy(), -scale * net.load.p_mw.to_numpy())
    p[0] = -p[1:].sum()
    return {
        'lines': net.line[['from_bus', 'to_bus']].to_numpy(),
        'x': x,
        'rating': rating,
        'p': p,
        'n_bus': len(net.bus),

def ptdf(case: dict, in_service: np.ndarray) -> np.ndarray | None:
    """PTDF of the lines in service (slack bus 0), or ``None`` when they do not connect every bus."""
    lines, n_bus = case['lines'][in_service], case['n_bus']
    a = np.zeros((len(lines), n_bus))
    a[np.arange(len(lines)), lines[:, 0]] = 1
    a[np.arange(len(lines)), lines[:, 1]] = -1
    adjacency = np.zeros((n_bus, n_bus))
    adjacency[lines[:, 0], lines[:, 1]] = 1
    if connected_components(adjacency, directed=False)[0] > 1:
        return None
    b = 1 / case['x'][in_service]
    bbus = a.T @ (b[:, None] * a)
    h = np.zeros((len(lines), n_bus))
    h[:, 1:] = (b[:, None] * a[:, 1:]) @ np.linalg.inv(bbus[1:, 1:])
    return h


def overload_energy(case: dict, switched_off: tuple[int, ...] = ()) -> float:
    """N-1 overload energy in MW of the network without the lines in ``switched_off``; ``inf`` when it is islanded.

    Sum over the non-bridge single outages and over every monitored line of the flow above the rating. The outage of
    a bridge (a line whose loss islands the grid, LODF denominator zero) is left out, as ToOp does.
    """
    in_service = np.ones(len(case['lines']), dtype=bool)
    in_service[list(switched_off)] = False
    h = ptdf(case, in_service)
    if h is None:
        return np.inf
    lines, rating = case['lines'][in_service], case['rating'][in_service]
    f = h @ case['p']
    hk = h[:, lines[:, 0]] - h[:, lines[:, 1]]  # column k: sensitivity to a transfer along line k
    denominator = 1 - np.diag(hk)
    not_bridge = np.abs(denominator) > 1e-9
    lodf = hk[:, not_bridge] / denominator[not_bridge]
    post = f[:, None] + lodf * f[not_bridge]  # (line, outage)
    post[np.flatnonzero(not_bridge), np.arange(not_bridge.sum())] = 0  # the outaged line carries nothing
    return float(np.maximum(0, np.abs(post) - rating[:, None]).sum())

      def enumerate_front(case: dict, k_max: int = K_MAX) -> tuple[np.ndarray, list[tuple[int, ...]], int]:

def _evaluate(case: dict, genome: np.ndarray, n_line: int) -> np.ndarray:
    """Objectives of a genome: sorted line indices padded with ``n_line`` (the sentinel of Chapter 24)."""
    switched = tuple(int(g) for g in genome if g < n_line)
    return np.array([min(overload_energy(case, switched), PENALTY), len(switched)])


def _random_genome(rng: np.random.Generator, n_line: int, k_max: int) -> np.ndarray:
    k = rng.integers(k_max + 1)
    g = np.full(k_max, n_line)
    g[:k] = rng.choice(n_line, k, replace=False)
    return np.sort(g)


def _mutate(rng: np.random.Generator, genome: np.ndarray, n_line: int) -> np.ndarray:
    g = genome.copy()
    slot = rng.integers(len(g))
    g[slot] = n_line if rng.random() < 0.3 else rng.integers(n_line)
    unique = np.unique(g[g < n_line])
    return np.concatenate([unique, np.full(len(g) - len(unique), n_line)])


def nsga2(case: dict, seed: int, evaluations: int = EVALUATIONS, pop: int = 24, k_max: int = K_MAX) -> np.ndarray:
    """A minimal NSGA-II (rank, then crowding distance) with the mutation of Chapter 24; returns the final front."""
    rng = np.random.default_rng(seed)
    n_line = len(case['lines'])
    genomes = np.array([_random_genome(rng, n_line, k_max) for _ in range(pop)])
    objectives = np.array([_evaluate(case, g, n_line) for g in genomes])
    used = pop
    while used < evaluations:
        children = np.array([_mutate(rng, genomes[rng.integers(pop)], n_line) for _ in range(pop)])
        child_obj = np.array([_evaluate(case, g, n_line) for g in children])
        used += pop
        genomes, objectives = np.vstack([genomes, children]), np.vstack([objectives, child_obj])
        ranks = pareto.fast_non_dominated_sort(objectives)
        crowd = pareto.crowding_distance(objectives, ranks)
        order = np.lexsort((-crowd, ranks))[:pop]
        genomes, objectives = genomes[order], objectives[order]
    finite = objectives[:, 0] < PENALTY
    front = objectives[finite][pareto.non_dominated_mask(objectives[finite])]
    return np.unique(front, axis=0)


def map_elites(case: dict, seed: int, evaluations: int = EVALUATIONS, k_max: int = K_MAX) -> np.ndarray:
    """MAP-Elites with one cell per number of switched lines, elite = lowest overload energy; returns its front."""
    rng = np.random.default_rng(seed)
    n_line = len(case['lines'])
    cells: dict[int, tuple[float, np.ndarray]] = {}
    for used in range(evaluations):
        parent = cells[rng.choice(list(cells))][1] if cells and used >= 50 else _random_genome(rng, n_line, k_max)
        genome = _mutate(rng, parent, n_line) if cells and used >= 50 else parent
        e, k = _evaluate(case, genome, n_line)
        if e < PENALTY and (int(k) not in cells or e < cells[int(k)][0]):
            cells[int(k)] = (e, genome)
    points = np.array([[e, k] for k, (e, _) in sorted(cells.items())])
    return points[pareto.non_dominated_mask(points)]

      def model() -> tuple[pulp.LpProblem, pulp.LpAffineExpression, pulp.LpAffineExpression]:
    """The feasible set of the facility location problem and its two objective expressions."""
    m = pulp.LpProblem('ufl_bi', pulp.LpMinimize)
    y = m.add_variable_dicts('open', list(FIXED), 0, 1, cat='Binary')
    x = m.add_variable_dicts('assign', list(ASSIGN), 0, 1)
    for j in CUSTOMERS:
        m += pulp.lpSum(x[i, j] for i in FIXED) == 1
    for i, j in ASSIGN:
        m += x[i, j] <= y[i]
    return m, pulp.lpSum(FIXED[i] * y[i] for i in FIXED), pulp.lpSum(ASSIGN[k] * x[k] for k in ASSIGN)


def lexmin(first: int, second: int) -> tuple[float, float]:
    """Payoff-table row: minimize objective ``first``, then objective ``second`` with the first held at its optimum."""
    m, f1, f2 = model()
    objectives = [f1, f2]
    m.setObjective(objectives[first])
    m.solve(pulp.HiGHS(msg=False))
    best = pulp.value(objectives[first])
    m += objectives[first] <= best + 1e-9
    m.setObjective(objectives[second])
    m.solve(pulp.HiGHS(msg=False))
    return pulp.value(f1), pulp.value(f2)


def augmecon2(grid_points: int = 20) -> tuple[list[tuple[float, float]], int]:
    """Exact Pareto set (f1, f2) and the number of MILPs solved.

    Objective 2 is constrained, ``f2 + s = e``, on a grid from its best to its worst payoff value; the objective is
    ``f1 - EPS * s / r2`` so that only efficient solutions are returned. When the slack covers ``b`` grid steps the
    next ``b`` grid points would return the same solution and are skipped (the bypass of AUGMECON2).
    """
    payoff = [lexmin(0, 1), lexmin(1, 0)]
    f2_min, f2_max = payoff[1][1], payoff[0][1]
    r2 = f2_max - f2_min
    step = r2 / grid_points
    solutions: list[tuple[float, float]] = []
    k, solved = 0, 0
    while k <= grid_points:
        e = f2_max - k * step
        m, f1, f2 = model()
        s = m.add_variable('slack', 0)
        m += f2 + s == e
        m.setObjective(f1 - EPS * s / r2)
        m.solve(pulp.HiGHS(msg=False))
        solved += 1
        if pulp.LpStatus[m.status] != 'Optimal':
            break
        point = (round(pulp.value(f1), 6), round(pulp.value(f2), 6))
        if point not in solutions:
            solutions.append(point)
        k += 1 + int(s.value() // step) if step > 0 else grid_points + 1
    return sorted(solutions), solved


def enumerate_front() -> list[tuple[float, float]]:
    """Every non-empty set of open facilities with the cheapest assignment, then the non-dominated ones."""
    points = []

    def dominates(a: np.ndarray, b: np.ndarray) -> bool:
    """``a`` weakly better in every objective and strictly better in at least one."""
    return bool(np.all(a <= b) and np.any(a < b))


def non_dominated_mask(points: np.ndarray) -> np.ndarray:
    """True for the points that no other point dominates (duplicates of a non-dominated point are kept)."""
    p = points[:, None, :]  # candidate
    q = points[None, :, :]  # possible dominator
    dominated_by = np.all(q <= p, axis=2) & np.any(q < p, axis=2)
    return ~dominated_by.any(axis=1)


def fast_non_dominated_sort(points: np.ndarray) -> np.ndarray:
    """Rank of every point (0 = first front) with the domination counts of Deb et al. 2002."""
    n = len(points)
    p, q = points[:, None, :], points[None, :, :]
    dom = np.all(p <= q, axis=2) & np.any(p < q, axis=2)  # dom[i, j]: i dominates j
    count = dom.sum(axis=0)  # how many dominate each point
    ranks = np.full(n, -1)
    front = np.flatnonzero(count == 0)
    rank = 0
    while front.size:
        ranks[front] = rank
        count = count - dom[front].sum(axis=0)
        count[ranks >= 0] = -1  # already assigned
        front = np.flatnonzero(count == 0)
        rank += 1
    return ranks


def crowding_distance(points: np.ndarray, ranks: np.ndarray) -> np.ndarray:
    """Crowding distance within each front; boundary points get ``inf`` (Deb et al. 2002)."""
    distance = np.zeros(len(points))
    for rank in np.unique(ranks):
        idx = np.flatnonzero(ranks == rank)
        if len(idx) <= 2:
            distance[idx] = np.inf
            continue
        for m in range(points.shape[1]):
            order = idx[np.argsort(points[idx, m], kind='stable')]
            span = points[order[-1], m] - points[order[0], m]
            distance[order[[0, -1]]] = np.inf
            if span > 0:
                distance[order[1:-1]] += (points[order[2:], m] - points[order[:-2], m]) / span
    return distance

    def hypervolume_2d(points: np.ndarray, reference: np.ndarray) -> float:
    """Area dominated by the two-objective ``points`` and bounded by ``reference``: sort by f1, add rectangles."""
    p = points[np.all(points < reference, axis=1)]
    if len(p) == 0:
        return 0.0
    p = p[non_dominated_mask(p)]
    p = p[np.argsort(p[:, 0])]
    widths = np.diff(np.r_[p[:, 0], reference[0]])
    heights = reference[1] - p[:, 1]
    return float((widths * heights).sum())


def igd_plus(front: np.ndarray, reference_front: np.ndarray) -> float:
    """IGD+ of Ishibuchi et al.: mean over reference points of the smallest dominance-aware distance to the front."""
    diff = np.maximum(front[None, :, :] - reference_front[:, None, :], 0)  # (reference, front, objective)
    return float(np.linalg.norm(diff, axis=2).min(axis=1).mean())


def epsilon_indicator(front: np.ndarray, reference_front: np.ndarray) -> float:
    """Additive epsilon indicator: the smallest shift that makes ``front`` weakly dominate every reference point."""
    diff = front[None, :, :] - reference_front[:, None, :]
    return float(diff.max(axis=2).min(axis=1).max())

    def reference_sweep(points: np.ndarray, factors=FACTORS) -> list[tuple[float, float, float]]:
    """``(factor, rectangles, moocore)`` hypervolumes for the reference point ``factor`` times the nadir."""
    nadir = points[pareto.non_dominated_mask(points)].max(axis=0)
    return [
        (float(f), pareto.hypervolume_2d(points, f * nadir), float(moocore.hypervolume(points, ref=f * nadir)))
        for f in factors
    ]


def random_fronts(n_fronts: int = 200, seed: int = 27) -> float:
    """Largest absolute difference between both implementations on random two-objective point sets."""
    rng = np.random.default_rng(seed)
    worst = 0.0
    for _ in range(n_fronts):
        points = rng.random((int(rng.integers(1, 40)), 2))
        reference = 1 + rng.random(2)
        worst = max(worst, abs(pareto.hypervolume_2d(points, reference) - moocore.hypervolume(points, ref=reference)))
    return worst

    Exercise 5¶

    The cell of a descriptor \((s, d)\) (split_subs, switching_distance) is ravel_multi_index((s, d), (5, 45), mode="clip") \(= 45 \min(s, 4) + \min(d, 44)\).

    Different cells, one dominates the other. Topology A: 1 split, switching distance 2, overload 10 MW, cell \(45 + 2 = 47\). Topology B: 2 splits, distance 5, overload 12 MW, cell \(90 + 5 = 95\). A dominates B in all three quantities and both are stored, each as the elite of its cell. The repertoire is a table of "best for this exact number of splits and switches", not a front: an operator who reads B's cell sees a valid elite and nothing tells them that a cheaper topology does the same job better. The non-dominated set (analyse) has to be extracted afterwards; on the synthetic table 19 of 30 elites are dominated.

    Same edge cell, different without clipping. Topologies with descriptors \((4, 44)\) and \((4, 60)\) both land in cell 224; so does \((7, 44)\). Without clipping, \((4, 60)\) and \((7, 44)\) would have cells of their own (or none, under exactly-equal constraints), and the cell "4 splits, 44 switches" would hold a topology with exactly those values. With clipping, the elite of the last cell on an axis is the best topology with at least 4 splits or at least 44 switching operations, so an operator who takes the cell label at face value underestimates the effort of the proposal, possibly by a lot. The label is a lower bound, and the only reliable numbers are the metrics stored with the elite (extra_scores), which table_from_res_json reads.

    def cell_index(descriptor, n_cells: tuple[int, ...] = N_CELLS) -> int:
    """ToOp's cell of a descriptor: every coordinate is clipped into its axis before raveling."""
    return int(np.ravel_multi_index(np.asarray(descriptor, dtype=int), n_cells, mode='clip'))


def exact_cell_index(descriptor, n_cells: tuple[int, ...] = N_CELLS) -> int | None:
    """The cell under "exactly equal" constraints: ``None`` when a coordinate lies outside its axis."""
    d = np.asarray(descriptor, dtype=int)
    if np.any(d < 0) or np.any(d >= np.asarray(n_cells)):
        return None
    return int(np.ravel_multi_index(d, n_cells))
