    Lab¶

    1. A reusable Newton solver. newton_solve below returns the solution, a success flag and the list of residual norms \(\|F(\mathbf{x}_k)\|\) (the starting point included). Each step is one linear solve \(J\,\Delta = -F\); np.linalg.LinAlgError (singular Jacobian) and a non-finite iterate end the run with success = False, and so does reaching max_iter above tol. The damping argument scales every step by a fixed fraction; backtrack=True halves that fraction until the residual decreases (step 5).

      newton_lab.py: newton_solve
      def newton_solve(f, jac, x0, tol: float = 1e-10, max_iter: int = 50, damping: float = 1.0, backtrack: bool = False):
    """Newton's method for F(x) = 0; returns (x, success, residual norms).

    Each step solves J(x) Δ = −F(x) and sets x ← x + damping · Δ. With ``backtrack`` the fraction starts at
    ``damping`` and is halved (at most ten times) until ‖F‖ decreases. The history holds ‖F(x_k)‖ for
    k = 0, 1, ... including the starting point. A singular Jacobian (``np.linalg.LinAlgError``) or a non-finite
    iterate ends the run with ``success = False`` instead of an exception; so does reaching ``max_iter``
    above ``tol``.
    """
    x = np.asarray(x0, float)
    history = [float(np.linalg.norm(f(x)))]
    for _ in range(max_iter):
        if history[-1] < tol:
            return x, True, history
        try:
            step = np.linalg.solve(jac(x), -f(x))
        except np.linalg.LinAlgError:
            return x, False, history
        alpha = damping
        for _ in range(MAX_HALVINGS + 1):
            with np.errstate(over='ignore', invalid='ignore'):
                xn = x + alpha * step
                r = float(np.linalg.norm(f(xn)))
            if not backtrack or (np.isfinite(r) and r < history[-1]):
                break
            alpha /= 2
        if not np.isfinite(r):
            return xn, False, history
        x = xn
        history.append(r)
    return x, history[-1] < tol, history

    2. Residual histories and convergence order. From \((1, -1)\) the norms are \(2.1\), \(8.6\cdot10^{-1}\), \(4.0\cdot10^{-2}\), \(1.0\cdot10^{-4}\), \(8.4\cdot10^{-10}\), \(0\): five steps to root A \(= (1.004169, -1.729637)\). From \((-1, 1)\): \(2.0\), \(1.0\), \(5.4\cdot10^{-2}\), \(1.8\cdot10^{-4}\), \(2.1\cdot10^{-9}\), \(0\), five steps to root B \(= (-1.816264, 0.837368)\). From \((2, 2)\) the residual first grows (\(9.3\), \(3.7\), \(3.4\), \(4.5\)) and then collapses (\(0.60\), \(2.0\cdot10^{-2}\), \(2.5\cdot10^{-5}\), \(4.0\cdot10^{-11}\)): seven steps, to root B, far from where it started. From \((0, 0)\) the Jacobian \(\begin{bmatrix} 0 & 0 \\ 1 & 1\end{bmatrix}\) is singular and the solver returns failure at once. On semilogy the three convergent histories bend downwards, the picture of quadratic convergence. The ratio \(\log r_{k+1} / \log r_k\) is \(2.85\) then \(2.27\) from \((1, -1)\), \(2.95\) then \(2.32\) from \((-1, 1)\), \(2.71\) then \(2.26\) from \((2, 2)\): it approaches 2 from above, because \(\log r_{k+1} / \log r_k = p + \log C / \log r_k\) for \(r_{k+1} \approx C r_k^p\), and the second term only vanishes as \(r_k \to 0\). The ratio for the first pair from \((1, -1)\) is \(21.4\) and means nothing: \(r_0 = 0.86\) is so close to 1 that its logarithm is nearly zero. Estimate the order from the tail of the history only.

    3. Basins of attraction. basins() iterates the \(200 \times 200\) starting points together (the \(2 \times 2\) Jacobian is inverted by Cramer's rule) and labels each point by the root within \(10^{-6}\) of its last iterate: 12 117 points reach root A, 27 673 reach root B and 210 fail (overflow or an exactly singular Jacobian). The map shows two broad regions, but the boundary between them is not a line: along the curve \(\det J = 2x - 2y e^x = 0\), that is \(y = x e^{-x}\), the picture is a ragged mixture of both colours, and 139 of the 210 failures lie within \(0.1\) of that curve. On the curve the Newton step is undefined; next to it the step is huge, so the iterate lands far away and in whichever basin that landing point belongs to. The boundary also follows the images of that curve under the Newton map (the points that reach the curve after one or more steps), which is why it looks fractal. Away from the curve the step is bounded and nearby starting points move together.

      newton_lab.py: basins
      def basins(n: int = 200, damping: float = 1.0, backtrack: bool = False, max_iter: int = 50) -> np.ndarray:
    """Which root Newton reaches from each point of an n × n grid over [−3, 3]²: 0 or 1 for ``ROOTS``, −1 for failure.

    All grid points are iterated together, with the same step rule as ``newton_solve`` (fixed fraction
    ``damping``, or backtracking from it). A point whose Jacobian is singular or whose iterate leaves the
    floating-point range is marked as failed and frozen. Returns the label matrix indexed as
    ``label[row = y index, column = x index]`` for ``plt.imshow``.
    """
    s = np.linspace(-3, 3, n)
    x, y = (a.ravel().copy() for a in np.meshgrid(s, s))
    alive = np.ones(x.size, bool)
    r_old = _residual_grid(x, y)
    for _ in range(max_iter):
        dx, dy = _newton_step_grid(x, y)
        alpha = np.full(x.size, damping)
        xn, yn = x + alpha * dx, y + alpha * dy
        r_new = _residual_grid(xn, yn)
        if backtrack:
            for _ in range(MAX_HALVINGS):
                retry = ~(np.isfinite(r_new) & (r_new < r_old))
                if not retry.any():
                    break
                alpha = np.where(retry, alpha / 2, alpha)
                xn, yn = x + alpha * dx, y + alpha * dy
                r_new = _residual_grid(xn, yn)
        ok = alive & np.isfinite(r_new) & (np.abs(xn) < 1e6) & (np.abs(yn) < 1e6)
        alive &= ok
        x, y = np.where(ok, xn, x), np.where(ok, yn, y)
        r_old = np.where(ok, r_new, r_old)
    pts = np.column_stack([x, y])
    dist = np.linalg.norm(pts[:, None, :] - ROOTS[None, :, :], axis=2)
    label = np.where(dist.min(axis=1) < 1e-6, dist.argmin(axis=1), -1)
    label[~alive] = -1
    return label.reshape(n, n)

    4. SciPy and Octave. From \((1, -1)\) to a residual of \(10^{-10}\):

      Solver Iterations Function evaluations
      newton_solve (analytic Jacobian) 5 6 (plus 5 Jacobians)
      optimize.root(..., method='hybr') not reported 13
      optimize.root(..., method='broyden1') 16 27
      Octave fsolve (Exercise 6) 6 16

      hybr is MINPACK's hybrid Powell method: a trust-region step with a Jacobian built by finite differences and then updated by Broyden's formula, so its nfev includes the two extra evaluations of each Jacobian rebuild and it reports no iteration count. broyden1 starts from the identity scaled by its alpha parameter, which is why it needs three times the iterations of Newton. Newton with an analytic Jacobian is hard to beat on a 2-variable problem; the comparison turns in favour of quasi-Newton methods when the Jacobian is expensive and the dimension large (Exercise 5).

      newton_lab.py: scipy_comparison
      def scipy_comparison(x0=(1.0, -1.0)) -> dict[str, tuple[int | None, int]]:
    """(iterations, function evaluations) of Newton, SciPy ``hybr`` and SciPy ``broyden1`` from ``x0``.

    Newton evaluates F once per iteration plus once at the start. ``hybr`` (MINPACK) reports only ``nfev``,
    which includes the finite-difference Jacobian (two evaluations per rebuild), so its iteration count is
    ``None``; ``broyden1`` reports ``nit`` and ``nfev``.
    """
    _, _, hist = newton_solve(residual, jacobian, x0)
    out: dict[str, tuple[int | None, int]] = {'newton': (len(hist) - 1, len(hist))}
    for method in ('hybr', 'broyden1'):
        sol = optimize.root(residual, x0, method=method, tol=1e-10)
        out[method] = (int(sol.nit) if 'nit' in sol else None, int(sol.nfev))
    return out

    5. Damping. A fixed damping=0.5 does not rescue the failures: 345 points fail instead of 210, because half a step from a point near the singular curve still lands far away, and halving every step keeps later iterates hovering near the curve for longer. Its cost near the solution is severe: the error is only halved each step (the convergence is linear with ratio \(1/2\), a straight line on semilogy), and the run from \((1, -1)\) takes 34 steps instead of 5. Backtracking (start from the full step, halve it until the residual decreases) removes every failure: 0 of the 40 000 points fail, 13 105 reach root A and 26 895 root B. Its cost near the solution is nil, because the full Newton step always decreases the residual there and is accepted at once: the run from \((1, -1)\) still takes 5 steps. Backtracking only pays for the extra residual evaluations of the rejected trial steps, far from the solution. In the basin map the ragged band along \(\det J = 0\) remains (the step is still huge there, only shortened until the residual improves), but every point now ends at one of the two roots.

    6. Keep the function. newton_solve in newton_lab.py takes any f and jac; in Chapter 15 the residual is the power mismatch and the Jacobian the power-flow Jacobian. Nothing to compute here.

    Exercise 1¶

    For \(f(x) = x^2 - 2\) the Newton step is \(x_{k+1} = x_k - (x_k^2 - 2)/(2x_k) = \tfrac12 (x_k + 2/x_k)\). From \(x_0 = 1\):

    \(k\) \(x_k\) \(e_k = \lvert x_k - \sqrt2 \rvert\) \(e_k / e_{k-1}^2\)
    0 \(1\) \(4.1\cdot10^{-1}\)
    1 \(1.5\) \(8.6\cdot10^{-2}\) \(0.500\)
    2 \(1.416667\) \(2.5\cdot10^{-3}\) \(0.333\)
    3 \(1.414216\) \(2.1\cdot10^{-6}\) \(0.353\)

    Subtracting \(\sqrt2\) from the step gives exactly \(x_{k+1} - \sqrt2 = (x_k - \sqrt2)^2 / (2x_k)\), so \(e_{k+1} = e_k^2 / (2x_k) \to e_k^2 / (2\sqrt2) = 0.354\, e_k^2\): the error is squared each step, with a constant that the last ratio already reproduces to three digits. sqrt2_iterates() prints the table.

    Exercise 2¶

    The Newton step on \(f(x) = \arctan x\), \(f'(x) = 1/(1 + x^2)\), is \(x_1 = x_0 - (1 + x_0^2)\arctan x_0\), so \(x_1 = -x_0\) exactly when \(2x_0 = (1 + x_0^2)\arctan x_0\). brentq on \([1, 2]\) gives \(x_0^\ast = 1.3917\), and from it the iteration flips sign forever. Below the threshold the sequence shrinks: from \(1.3\) the iterates are \(-1.16\), \(0.859\), \(-0.374\), \(0.034\), \(-2.6\cdot10^{-5}\), \(1.2\cdot10^{-14}\). Above it the sequence grows: from \(1.5\) they are \(-1.69\), \(2.32\), \(-5.11\), \(32.3\), \(-1.6\cdot10^{3}\), \(3.9\cdot10^{6}\), because far from the origin \(f'\) is tiny and each step \(\approx x^2 \arctan x\) overshoots by more than the distance to the root. With damping=0.5 from \(1.5\) the first half-step lands at \(-0.097\), inside the convergent region, and from there the iterates halve each step (\(-0.048\), \(-0.024\), \(-0.012\), ...): the divergence is cured but the convergence is now linear with ratio \(1/2\), the price of a fixed damping. The backtracking rule of the lab's newton_solve (shorten the step only while the residual does not decrease) converges from \(1.5\) in 4 steps: it damps the first step and takes full Newton steps afterwards.

    def arctan_critical_point() -> float:

    Exercise 3¶

    With \(f(x) = (x - 1)^2\) and \(f'(x) = 2(x - 1)\) the step is \(x_{k+1} = x_k - (x_k - 1)/2 = (x_k + 1)/2\), so the error obeys \(e_{k+1} = e_k / 2\) exactly. From \(x_0 = 0\): \(0.5\), \(0.75\), \(0.875\), \(0.9375\), \(0.96875\), \(0.984375\), with errors \(1/2\), \(1/4\), \(1/8\), ... (double_root_iterates()). The quadratic estimate \(e_{k+1} = f''(\xi)\, e_k^2 / (2 f'(x_k))\) assumes \(f'(x_k) \to f'(r) \neq 0\); at a double root \(f'(x_k) = 2 e_k\) itself vanishes with the error, and the estimate degrades to \(e_{k+1} = 2 e_k^2 / (4 e_k) = e_k / 2\). In general a root of multiplicity \(m\) gives linear convergence with ratio \((m - 1)/m\). The practical sign is a residual that shrinks by a constant factor per step instead of squaring: in a power flow that is the signature of a case at its loadability limit, where the Jacobian becomes singular (Exercise 4).

    Exercise 4¶

    Newton on \(g(\delta) = \sin\delta - PX\), \(g'(\delta) = \cos\delta\), from \(\delta_0 = 0\) (angle_iterates):

    \(PX\) Iterates (rad) Result
    \(0.5\) \(0.5\), \(0.5234\), \(0.5236\) \(\delta = 30.00^\circ\) in 3 steps
    \(0.99\) \(0.99\), \(1.2706\), \(1.3880\), \(1.4246\), \(1.4292\), \(1.4293\) \(\delta = 81.89^\circ\) in 6 steps
    \(1.2\) \(1.2\), \(1.9395\), \(1.1981\), \(1.9359\), \(1.1911\), \(1.9228\), \(1.1650\), \(1.8773\), ... no convergence

    For \(PX = 0.99\) the convergence is slow at first because the root sits where \(\cos\delta = 0.141\) is small: the constant \(g''/(2g') = \tan\delta / 2 \approx 3.5\) is large, and the first full step from \(0\) (slope 1) undershoots badly. For \(PX = 1.2\) the equation has no real solution, since \(\sin\delta \le 1 < 1.2\): the iterates bounce between about \(1.2\) and \(1.9\) on either side of the maximum of \(\sin\delta\), the residual never drops below \(0.2\), and after a dozen steps the sequence is still wandering (the last iterates computed are \(1.06\), \(1.73\), \(0.39\), \(1.28\)). A power flow solver stops at its iteration cap and reports non-convergence. Physically \(P_{\max} = 1/X\) is the steady-state stability limit of the line; a dispatch asking for more has no equilibrium. ToOp's AC validation runs Newton–Raphson power flows on each candidate topology; a topology that drives a load flow past such a limit does not produce a flow to check against the ratings, so the fact itself is counted in the non_converging_loadflows metric and the candidate is penalised.

    Exercise 5¶

    Good Broyden with \(B_0 = J(\mathbf{x}_0)\): the step is \(\Delta = -H F(\mathbf{x})\) with \(H = B^{-1}\), and after the step, with \(s = \Delta\) and \(y = F(\mathbf{x} + \Delta) - F(\mathbf{x})\), the rank-1 update \(B^+ = B + (y - Bs)\, s^\top / (s^\top s)\) keeps \(B^+ s = y\) (the secant condition) while changing \(B\) as little as possible. Sherman–Morrison (Chapter 4) turns it into an update of the inverse without any linear solve:

    \[ H^+ = H + \frac{(s - Hy)\, s^\top H}{s^\top H y}. \]

    From \((1, -1)\) Broyden takes 7 iterations against Newton's 5, with residual norms \(2.1\), \(8.6\cdot10^{-1}\), \(1.6\cdot10^{-1}\), \(8.5\cdot10^{-3}\), \(2.7\cdot10^{-5}\), \(2.2\cdot10^{-6}\), \(4.1\cdot10^{-8}\), \(9.6\cdot10^{-12}\): the first step is Newton's (same \(B_0\)), and afterwards the decrease is superlinear but not quadratic. Started from \(B_0 = I\) it needs 13 iterations. Each Broyden iteration costs one residual evaluation and an \(O(n^2)\) update instead of a Jacobian evaluation and an \(O(n^3)\) solve, so it wins when the Jacobian is expensive or unavailable, as in hybr, which uses the same update between rebuilds.

    newton_exercises.py: broyden_good
    def broyden_good(f, x0, j0, tol: float = 1e-10, max_iter: int = 50) -> tuple[np.ndarray, list[float]]:
    """Broyden's 'good' method with the inverse Jacobian kept by Sherman–Morrison; returns (x, residual norms).

    From B₀ = J(x₀) the step is Δ = −H F(x), H = B⁻¹. With s = Δ and y = F(x + Δ) − F(x) the good update is
    B⁺ = B + (y − B s) sᵀ / (sᵀ s), whose inverse (Sherman–Morrison) is H⁺ = H + (s − H y) sᵀ H / (sᵀ H y).
    The history holds ‖F(x_k)‖ for k = 0, 1, ...
    """
    x = np.asarray(x0, float)
    h = np.linalg.inv(np.asarray(j0, float))
    fx = f(x)
    history = [float(np.linalg.norm(fx))]
    for _ in range(max_iter):
        if history[-1] < tol:
            break
        s = -h @ fx
        x = x + s
        fx_new = f(x)
        y = fx_new - fx
        hy = h @ y
        h = h + np.outer(s - hy, s @ h) / (s @ hy)
        fx = fx_new
        history.append(float(np.linalg.norm(fx)))
    return x, history

    Exercise 6¶

    Octave's fsolve (trust-region dogleg, Jacobian by finite differences unless supplied) from \([1; -1]\) with TolFun = TolX = 1e-12 returns \(x = (1.0042, -1.7296)\), \(\|f\| = 9\cdot10^{-16}\), info = 1 (converged) and output.iterations = 6, output.successful = 5, output.funcCount = 16. The Newton code of the lab takes 5 iterations with 6 residual and 5 Jacobian evaluations; fsolve spends one more iteration and 16 function evaluations, because each finite-difference Jacobian costs two extra evaluations and one of its trial steps was rejected (successful counts the accepted ones). From \([-1; 1]\) it finds the other root in 6 iterations too.
