    Chapter 13 – Solutions¶

    Solutions of the Lab and the Exercises of Chapter 13. Try each task before reading its solution. The code is in the chapter's src folder: coupler_splits.py (the worked example), reassignment_distance.py (Exercise 4 and the station used in the Lab), ring_splits.py (Exercise 3), four_substations.py (Exercise 5) and station_toop.py, which runs ToOp's own prepare_for_separation_set, make_optimal_separation_set and per_station_switching_distance (Lab steps 1–4; ToOp's interpreter only). The ToOp numbers were produced with ToOp ba1874e on CPU; each module's main() prints every number quoted below.

    Lab¶

    The lab names the interactive ToOp notebook notebooks/example_asset_topology_analysis.ipynb. Its widgets and single-line diagrams need a browser session and are not run here; the same materialization of a node-breaker network into ToOp's bus groups, without widgets, is what station_toop.four_substations_bus_groups does, with the functions the notebook itself imports (get_node_breaker_master_asset_topology, materialize_runtime_bus_groups_from_network_state). The network is pypowsybl's four-substations node-breaker example, the one Exercise 5 also uses.

    1. Node-breaker graph of a voltage level. The five voltage levels of the example become five bus groups. Four of them (S1VL1, S2VL1, S3VL1, S4VL1) have a single busbar section and no coupler: ToOp logs "No couplers found in the substation" and they cannot be split. S1VL2, the 400 kV level of substation S1, is a double busbar:

      busbar int_id bays closed onto it
      S1VL2_BBS1 0 TWT (branch), GH1, GH2, GH3, SHUNT
      S1VL2_BBS2 1 LCC1, LD2, LD3, LD4, VSC1

      joined by the coupler S1VL2_COUPLER (a breaker, closed, between int_ids 0 and 1, with a disconnector on each side). Every bay is a breaker plus one busbar disconnector per busbar section (the 33 switches of Exercise 5). In the single-line diagram the two horizontal busbar sections, the coupler between them and the ten bays hanging from them are exactly these objects; the bus-branch model sees one bus (the coupler is closed) with one branch and nine injections.

    2. Coupler states by hand. S1VL2 has one coupler and two busbars, so \(2^1 = 2\) states: coupler closed, one electrical busbar (the current state, skipped); coupler open, two electrical busbars \(\{\text{BBS1}\} \mid \{\text{BBS2}\}\). One candidate. For the worked example's chain of four busbars and three closed couplers, coupler_splits.two_node_configurations lists the three states with exactly one coupler open: open \(c_{01}\) gives \(\{b_0\} \mid \{b_1 b_2 b_3\}\), open \(c_{12}\) gives \(\{b_0 b_1\} \mid \{b_2 b_3\}\), open \(c_{23}\) gives \(\{b_0 b_1 b_2\} \mid \{b_3\}\). With six line bays L0, L1 on \(b_0\), L2 on \(b_1\), L3 on \(b_2\) and L4, L5 on \(b_3\) (reassignment_distance.ASSET_BUSBAR), the candidates are A = {L0 L1} | B = {L2 L3 L4 L5}, A = {L0 L1 L2} | B = {L3 L4 L5} and A = {L0 L1 L2 L3} | B = {L4 L5}.

    3. ToOp's separation set. station_toop.separation runs prepare_for_separation_set (nothing to fix: StationProblems is empty for both stations) and make_optimal_separation_set. For S1VL2 the separation set has shape (1, 2, 1): one configuration, two busbars, one branch asset (the table covers the branches, TWT on bus A, so [[1], [0]]), with coupler_states = [[True]] (the coupler must be open), busbar_a = [{0}] and coupler_distance = [1], since the coupler is closed today. For the chain station the set has three configurations, in ToOp's order the same three splits as the hand enumeration (the script checks every row against coupler_splits, mirror images allowed, and prints same candidates as coupler_splits: True):

      coupler state (True = open) busbars in A bus A bus B
      \(c_{01}\) open {0} L0 L1 L2 L3 L4 L5
      \(c_{12}\) open {0, 1} L0 L1 L2 L3 L4 L5
      \(c_{23}\) open {0, 1, 2} L0 L1 L2 L3 L4 L5

      make_optimal_separation_set removes nothing: the three rows are distinct even up to the A/B mirror, and with fewer than clip_at_size = 100 rows no Hamming clipping applies.

    4. Switching distance of a target. All couplers are closed today (current_coupler_state = [F, F, F]). station_toop.switching_distance calls per_station_switching_distance; the pure NumPy reassignment_distance.reassignment_distance gives the same reassignment count in every case:

      target (True = on bus B) best configuration inverted reassignment coupler
      L3 L4 L5 on B 1 (\(c_{12}\) open) no 0 1
      L3 L4 on B, L5 on A 1 (\(c_{12}\) open) no 2 1
      L0 L1 L2 on B (the mirror of the first) 1 (\(c_{12}\) open) yes 0 1

      By hand: the first target is the second candidate, so no bay changes busbar, and the only physical operation is opening \(c_{12}\), one coupler switching. In the second target L5 must leave the group of \(b_3\) for the other side: its connection to a bus-B busbar is opened and a connection to a bus-A busbar is closed, two reassignment operations, plus the coupler. The third target is the first one with the names A and B exchanged; without the swap it would cost 12 (every one of the six bays on both rows), with it ToOp reports invert = True and distance 0, which is the reason the minimum over both labelings exists.

      station_toop.py
      """ToOp's separation set and switching distance for two stations (Chapter 13, Lab steps 1–4).

Runs with ToOp's interpreter only. The first station is the worked example's chain of four busbars and three
couplers with six line bays (the same station as ``reassignment_distance.py``), built here as a ``RuntimeBusGroup``
by hand. The second is voltage level S1VL2 of pypowsybl's four-substations node-breaker network, the double-busbar
level with one coupler, materialized with the same ToOp functions as ``notebooks/example_asset_topology_analysis``.
"""

import sys
import tempfile
from dataclasses import replace
from pathlib import Path

import jax.numpy as jnp
import numpy as np
import pypowsybl as pp
from reassignment_distance import ASSET_BUSBAR, ASSET_NAMES, N_BUSBARS, asset_table, candidates, reassignment_distance
from toop_engine_dc_solver.preprocess.helpers.switching_distance import per_station_switching_distance
from toop_engine_dc_solver.preprocess.preprocess_switching import (
    OptimalSeparationSetInfo,
    make_optimal_separation_set,
    prepare_for_separation_set,
)
from toop_engine_grid_helpers.powsybl.example_grids import create_default_network_masks
from toop_engine_grid_helpers.powsybl.powsybl_asset_topo import materialize_runtime_bus_groups_from_network_state
from toop_engine_grid_helpers.powsybl.powsybl_station_to_graph import get_node_breaker_master_asset_topology
from toop_engine_interfaces.asset_topology.assets_runtime import (
    RuntimeBranchAsset,
    RuntimeBusbar,
    RuntimeBusbarCoupler,
)
from toop_engine_interfaces.asset_topology.runtime_topology import RuntimeAssetConnection, RuntimeBusGroup
from toop_engine_interfaces.messages.preprocess.preprocess_commands import AreaSettings, CgmesImporterParameters

CHAIN_COUPLERS = [(0, 1), (1, 2), (2, 3)]


def chain_station() -> RuntimeBusGroup:
    """The worked example as a ToOp bus group: busbars b0..b3, closed breakers c01, c12, c23, six line bays."""
    busbars = [RuntimeBusbar(grid_model_id=f'b{i}', int_id=i) for i in range(N_BUSBARS)]
    couplers = [
        RuntimeBusbarCoupler(
            grid_model_id=f'c{a}{b}', coupler_type='BREAKER', busbar_from_id=a, busbar_to_id=b, open=False
        )
        for a, b in CHAIN_COUPLERS
    ]
    branches = [RuntimeAssetConnection(asset=RuntimeBranchAsset(grid_model_id=name)) for name in ASSET_NAMES]
    return RuntimeBusGroup(
        bus_group_id='chain',
        busbars=busbars,
        couplers=couplers,
        branch_connections=branches,
        injection_connections=[],
        branch_switching_table=asset_table(ASSET_BUSBAR, N_BUSBARS),
        injection_switching_table=np.zeros((N_BUSBARS, 0), dtype=bool),
    )


def four_substations_bus_groups(folder: Path) -> list[RuntimeBusGroup]:
    """The runtime bus groups of pypowsybl's four-substations network, one per voltage level.

    The network is saved as XIIDM into ``folder`` because ToOp's importer parameters name a grid file; every
    substation is marked relevant so that each voltage level becomes a bus group.
    """
    net = pp.network.create_four_substations_node_breaker_network()
    grid = folder / 'four_substations.xiidm'
    net.save(str(grid))
    masks = create_default_network_masks(net)
    masks = replace(
        masks,
        relevant_subs=np.ones(len(net.get_buses()), dtype=bool),
        busbar_for_nminus1=np.ones(len(net.get_busbar_sections()), dtype=bool),
    )
    parameters = CgmesImporterParameters(
        area_settings=AreaSettings(control_area=[''], view_area=[''], nminus1_area=[''], cutoff_voltage=1),
        data_folder=folder,
        grid_model_file=grid,
    )
    master = get_node_breaker_master_asset_topology(network=net, network_masks=masks, importer_parameters=parameters)
    return materialize_runtime_bus_groups_from_network_state(network=net, master_data=master)


def separation(group: RuntimeBusGroup) -> OptimalSeparationSetInfo:
    """Prepare a bus group and build its optimal separation set, as ToOp's preprocessing does."""
    branch_ids = [c.asset.grid_model_id for c in group.branch_connections]
    injection_ids = [c.asset.grid_model_id for c in group.injection_connections]
    simplified, _problems = prepare_for_separation_set(group, branch_ids, injection_ids)
    return make_optimal_separation_set(simplified)


def switching_distance(
    info: OptimalSeparationSetInfo, current_coupler_state: np.ndarray, target: np.ndarray
) -> tuple[int, bool, int, int]:
    """Best configuration, whether A and B were swapped, reassignment distance and coupler distance of a target."""
    best, invert, reassignment, coupler = per_station_switching_distance(
        jnp.asarray(target, dtype=bool),
        jnp.asarray(current_coupler_state, dtype=bool),
        jnp.asarray(info.separation_set),
        jnp.asarray(info.coupler_states),
    )
    return int(best), bool(invert), int(reassignment), int(coupler)


def describe_group(group: RuntimeBusGroup) -> str:
    """One line per busbar, coupler and asset of a bus group."""
    lines = [f'bus group {group.bus_group_id} (voltage level {group.voltage_level_id})']
    lines += [f'  busbar {b.grid_model_id} (int_id {b.int_id})' for b in group.busbars]
    lines += [
        f'  coupler {c.grid_model_id} {c.coupler_type} b{c.busbar_from_id}-b{c.busbar_to_id} open={c.open}'
        for c in group.couplers
    ]
    for row, busbar in zip(group.asset_switching_table, group.busbars, strict=True):
        assets = [a.grid_model_id for a, on in zip(group.assets, row, strict=True) if on]
        lines.append(f'  on {busbar.grid_model_id}: {assets}')
    return '\n'.join(lines)


def main(folder: Path) -> None:
    """Print the bus groups of the four-substations network, the separation sets and the switching distances."""
    groups = four_substations_bus_groups(folder)
    for group in groups:
        print(describe_group(group))
    s1vl2 = next(g for g in groups if g.voltage_level_id == 'S1VL2')
    info = separation(s1vl2)
    print(
        'S1VL2 separation set',
        info.separation_set.astype(int).tolist(),
        'coupler states',
        info.coupler_states.astype(int).tolist(),
    )
    print('S1VL2 busbar A', info.busbar_a, 'coupler distance', np.asarray(info.coupler_distance).tolist())

    chain = chain_station()
    info = separation(chain)
    print('chain: configurations', info.separation_set.shape[0], 'coupler states (True = open):')
    for state, group_a, row in zip(info.coupler_states, info.busbar_a, info.separation_set, strict=True):
        a = [n for n, on in zip(ASSET_NAMES, row[0], strict=True) if on]
        b = [n for n, on in zip(ASSET_NAMES, row[1], strict=True) if on]
        print(f'  open {state.astype(int).tolist()} busbars A {sorted(group_a)}: A = {a}, B = {b}')
    mine = candidates(CHAIN_COUPLERS, ASSET_BUSBAR)
    same = all(any((row == c).all() or (row[::-1] == c).all() for c in mine) for row in info.separation_set)
    print('chain: same candidates as coupler_splits:', same)
    closed = np.zeros(len(CHAIN_COUPLERS), dtype=bool)
    for label, target in (
        ('L3 L4 L5 on B', np.array([0, 0, 0, 1, 1, 1], dtype=bool)),
        ('L3 L4 on B (L5 moves)', np.array([0, 0, 0, 1, 1, 0], dtype=bool)),
        ('L0 L1 L2 on B (mirror)', np.array([1, 1, 1, 0, 0, 0], dtype=bool)),
    ):
        best, invert, reassignment, coupler = switching_distance(info, closed, target)
        numpy_best = int(reassignment_distance(mine, target).min())
        print(f'target {label}: best {best}, invert {invert}, reassignment {reassignment}, coupler {coupler}')
        print(f'  numpy reassignment_distance: {numpy_best}')


if __name__ == '__main__':
    main(Path(sys.argv[1]) if len(sys.argv) > 1 else Path(tempfile.mkdtemp()))

    Exercise 1¶

    The station: two busbars BB1 and BB2, four line bays L1–L4 and one coupler bay. In a double-busbar, single-breaker arrangement each line bay has one circuit breaker CB and two busbar disconnectors, DS-1 towards BB1 and DS-2 towards BB2 (plus a line disconnector on the line side, which plays no part here); the coupler bay has a breaker CB-C with a disconnector on each side. Take L1, L2 on BB1 and L3, L4 on BB2 with the coupler closed.

    Node-breaker. Every conductor segment is a node and every switch is an edge between two nodes. Per line bay: node \(n_\text{line}\) (the line end), edge CB to node \(n_\text{bay}\) (the busbar-side segment), edge DS-1 from \(n_\text{bay}\) to BB1 and edge DS-2 from \(n_\text{bay}\) to BB2, one of them closed. The coupler bay is the path BB1 – DS – \(n_c\) – CB-C – \(n_c'\) – DS – BB2. In total 2 busbar nodes, 4 × 2 bay nodes, 2 coupler nodes and 4 × 3 + 3 = 15 switches (plus the four line disconnectors if drawn), exactly the pattern of S1VL2 in Exercise 5.

    flowchart LR
    BB1((BB1)) ---|DS-1 closed| n1["bay 1"] ---|CB| L1
    BB2((BB2)) -.-|DS-2 open| n1
    BB1 ---|DS-1 closed| n2["bay 2"] ---|CB| L2
    BB2 -.-|DS-2 open| n2
    BB1 -.-|DS-1 open| n3["bay 3"] ---|CB| L3
    BB2 ---|DS-2 closed| n3
    BB1 -.-|DS-1 open| n4["bay 4"] ---|CB| L4
    BB2 ---|DS-2 closed| n4
    BB1 ---|DS| c1["coupler"] ---|CB-C closed| c2["bay"] ---|DS| BB2

    Bus-breaker. Disconnectors are resolved: each bay is attached to the busbar whose disconnector is closed, and only the breakers remain as switches. Two buses, BB1 with L1 and L2 and BB2 with L3 and L4, each line behind its breaker, and the coupler breaker between the two buses. This is the view pypowsybl's bus-breaker voltage levels keep and the one ToOp's RuntimeBusGroup encodes: a branch_switching_table with a row per busbar (here [[1, 1, 0, 0], [0, 0, 1, 1]]) and the list of couplers with their open/closed state.

    Bus-branch. Closed breakers disappear too, and busbars joined by a closed coupler merge: one bus with the four lines (the unsplit station). With the coupler open there are two buses, {L1, L2} and {L3, L4}, which is what a power flow or ToOp's DC solver sees, and nothing else: the bus-branch model cannot tell which physical busbar a line is on, only which electrical node.

    Moving L3 from BB2 to BB1. With the coupler closed (BB1 and BB2 at the same potential), close DS-1 of bay 3, then open DS-2 of bay 3: two switch operations in the node-breaker model, none in the bus-branch model (the electrical topology is unchanged while the coupler is closed). ToOp counts exactly these two, one connection closed and one opened, as a reassignment distance of 2 (Exercise 4); if the coupler were open it would first have to be closed, and that operation counts in the coupler distance. If the goal is a split with L3 on the BB1 side, the coupler is opened afterwards (one more operation, the coupler distance of Lab step 4).

    Exercise 2¶

    A disconnector (isolator) is a slow, air-insulated knife switch without an arc-quenching chamber. Opening a circuit that carries load current draws an arc; a circuit breaker extinguishes it with SF₆, vacuum or oil and a fast mechanism, a disconnector cannot, so the arc would persist, re-strike and flash over to earth or to the other phases. Disconnectors are therefore rated to open and close only de-energized circuits or circuits that carry no current to interrupt, and their task is isolation (a visible gap for maintenance) and selection (which busbar a bay uses), not switching. Interlocks in the substation enforce this: a busbar disconnector cannot be operated unless either its bay breaker is open or a parallel path at the same potential exists.

    For a busbar reassignment under load the parallel path is the coupler. The sequence is "make before break":

    1. Close the coupler breaker (if it was open): BB1 and BB2 are now one electrical node at the same voltage.
    2. Close the disconnector of the bay towards the new busbar: it closes between two points at the same potential, so no current flows through it at the moment of closing and nothing has to be interrupted.
    3. Open the disconnector towards the old busbar: the bay current it carried diverts through the new disconnector, the new busbar and the coupler, so again it interrupts no load current (only a small circulating current, within the rating of the disconnector).
    4. Repeat for every bay that moves; then, if the intention is to split the station, open the coupler breaker, the one device in the sequence that interrupts a real current.

    Consequences for the switching distance: a bay reassignment always costs two disconnector operations (ToOp's reassignment distance of 2 per moved asset), the coupler must be closed during the move, and a split is only completed by a breaker, so the coupler distance is counted separately. It also fixes the order in time: the reassignments come first and the coupler opens last, which is why a target split cannot be reached with fewer operations than ToOp's reassignment plus coupler count.

    Exercise 3¶

    A ring of \(n\) busbars with \(n\) couplers (busbar \(i\) joined to busbar \(i + 1 \bmod n\)) stays connected with one coupler open (a chain) and falls into exactly two groups when exactly two couplers are open; a third open coupler makes three groups. Hence the two-component states are the ways of choosing the two open couplers, \(\binom{n}{2}\). ring_splits.count_two_component_states runs the brute force of the worked example (coupler_splits.two_node_configurations over all \(2^n\) states) and closed_form gives \(\binom{n}{2}\); they agree for every \(n\) from 3 to 16 (the test checks 3–10):

    \(n\) states \(2^n\) two-component states \(\binom{n}{2}\) seconds
    3 8 3 3 0.000
    4 16 6 6 0.000
    6 64 15 15 0.001
    8 256 28 28 0.003
    10 1,024 45 45 0.015
    12 4,096 66 66 0.073
    14 16,384 91 91 0.307
    16 65,536 120 120 1.333

    The times are from one run on the maintainer's laptop and vary by machine, but the growth does not: each extra coupler doubles the number of states and the time, while the number of useful states grows only quadratically. Extrapolating the last row, \(n = 20\) takes about \(1.33 \times 2^4 \approx 21\) s and \(n = 30\) about six hours. That is why make_separation_set refuses stations with more than 20 couplers: a brute force over coupler states is affordable for the handful of couplers a real station has, and the limit guards against a mis-modelled station (for example, every bay disconnector counted as a coupler) rather than against a real design.

    ring_splits.py
    """Two-component coupler states of a ring of busbars, by brute force and in closed form (Chapter 13, Exercise 3).

A ring of n busbars joined by n couplers falls into exactly two connected groups when exactly two couplers are
open, so the count is n choose 2. The brute force of ``coupler_splits.two_node_configurations`` visits all 2**n
coupler states, which is what bounds ToOp's enumeration to 20 couplers.
"""

import time
from math import comb

from coupler_splits import two_node_configurations


def ring_couplers(n: int) -> list[tuple[int, int]]:
    """The n couplers of a ring of n busbars: busbar i joined to busbar (i + 1) mod n."""
    return [(i, (i + 1) % n) for i in range(n)]


def count_two_component_states(n: int) -> int:
    """Brute-force count of the coupler states of a ring of n busbars that leave exactly two components."""
    return len(two_node_configurations(ring_couplers(n), n))


def closed_form(n: int) -> int:
    """The binomial coefficient n choose 2: the two-component states open exactly two of the n couplers of the ring."""
    return comb(n, 2)


def timed_count(n: int) -> tuple[int, float]:
    """The brute-force count for a ring of n busbars and the wall-clock seconds it took."""
    start = time.perf_counter()
    count = count_two_component_states(n)
    return count, time.perf_counter() - start


def main(n_max: int = 16) -> None:
    """Print count, closed form and time for n = 3 .. n_max, then extrapolate the time to ToOp's limit of 20."""
    print(' n  states  count  C(n,2)  seconds')
    last = 0.0
    for n in range(3, n_max + 1):
        count, seconds = timed_count(n)
        print(f'{n:2d}  {2**n:6d}  {count:5d}  {closed_form(n):6d}  {seconds:7.3f}')
        last = seconds
    print(f'doubling per coupler: about {last * 2 ** (20 - n_max):.0f} s for n = 20 on this machine')


if __name__ == '__main__':
    main()

    Exercise 4¶

    With the candidates as a Boolean array cands of shape (candidates, 2, assets) and the target t (True = on bus B), the distance of every candidate, with and without the swap, is one expression each:

    direct  = (cands[:, 0] ^ ~t).sum(axis=1) + (cands[:, 1] ^ t).sum(axis=1)
swapped = (cands[:, 0] ^ t).sum(axis=1) + (cands[:, 1] ^ ~t).sum(axis=1)
distance = np.minimum(direct, swapped)

    Bus A is compared with the complement of the target (the assets that should not be on B) and bus B with the target; broadcasting does it for all candidates at once. For the worked example's station (six bays, candidates A = {L0 L1} | B = {L2 L3 L4 L5}, A = {L0 L1 L2} | B = {L3 L4 L5}, A = {L0 L1 L2 L3} | B = {L4 L5}) and the target "L3 L4 L5 on bus B" the distances are [2, 0, 2] with or without the swap: the second candidate is the target, and the neighbours differ by one bay, which counts twice (one connection to open, one to close).

    Where ignoring the swap overstates. Take the mirror target "L0 L1 L2 on bus B", the same split with the names of the two buses exchanged. Without the swap the distances are [10, 12, 10]: bus A of the second candidate disagrees with \(\bar t\) on all six assets and bus B disagrees with \(t\) on all six, although not a single bay has to move. With the swap they are [2, 0, 2] again. The names A and B are arbitrary labels of the two electrical nodes, so a distance that depends on them would make the engine pay twelve switching operations for renaming; this is what the invert flag of per_station_switching_distance records (Lab step 4). In general, without the swap the distance of a candidate to its own mirror is \(2m\) for \(m\) assets, the maximum possible, instead of 0.

    reassignment_distance.py
    """Vectorized reassignment distance of the worked example's station, with and without the A/B swap (Chapter 13).

The station is the chain of four busbars and three couplers of the worked example, with six line bays: lines 0
and 1 on busbar 0, line 2 on busbar 1, line 3 on busbar 2, lines 4 and 5 on busbar 3. A candidate is a pair of
Boolean rows (bus A, bus B) over the assets; a target is one Boolean row, True meaning "on bus B". The distance of
a candidate is the number of asset-busbar connections that differ, counted on bus A against the complement of the
target and on bus B against the target; ToOp also tries the target with A and B swapped and keeps the smaller sum.
"""

import numpy as np
from coupler_splits import COUPLERS, two_node_configurations

N_BUSBARS = 4
ASSET_BUSBAR = np.array([0, 0, 1, 2, 3, 3])  # busbar of each of the six line bays
ASSET_NAMES = [f'L{i}' for i in range(len(ASSET_BUSBAR))]


def asset_table(asset_busbar: np.ndarray = ASSET_BUSBAR, n_busbars: int = N_BUSBARS) -> np.ndarray:
    """Boolean table of shape (busbars, assets): True where the asset's bay is closed onto that busbar."""
    return np.arange(n_busbars)[:, None] == asset_busbar[None, :]


def candidates(couplers: list[tuple[int, int]] = COUPLERS, asset_busbar: np.ndarray = ASSET_BUSBAR) -> np.ndarray:
    """All two-component coupler states as a Boolean array of shape (candidates, 2, assets).

    Row 0 of each candidate marks the assets whose busbar lies in the first component, row 1 those in the second.
    """
    n_busbars = int(asset_busbar.max()) + 1
    table = asset_table(asset_busbar, n_busbars)
    out = []
    for _, parts in two_node_configurations(couplers, n_busbars):
        out.append(np.stack([table[sorted(part)].any(axis=0) for part in parts]))
    return np.array(out)


def reassignment_distance(cands: np.ndarray, target: np.ndarray, allow_swap: bool = True) -> np.ndarray:
    """Reassignment distance of every candidate to a target, one vectorized expression.

    Args:
        cands: Boolean array (candidates, 2, assets), bus A first, bus B second.
        target: Boolean array (assets,), True for the assets that should end on bus B.
        allow_swap: Also compare with the roles of A and B exchanged and keep the smaller distance, as ToOp does.
    """
    direct = (cands[:, 0] ^ ~target).sum(axis=1) + (cands[:, 1] ^ target).sum(axis=1)
    if not allow_swap:
        return direct
    swapped = (cands[:, 0] ^ target).sum(axis=1) + (cands[:, 1] ^ ~target).sum(axis=1)
    return np.minimum(direct, swapped)


def describe(cand: np.ndarray) -> str:
    """The two busbar groups of a candidate as asset names, for printing."""
    a = ' '.join(n for n, on in zip(ASSET_NAMES, cand[0], strict=True) if on)
    b = ' '.join(n for n, on in zip(ASSET_NAMES, cand[1], strict=True) if on)
    return f'A = {{{a}}}, B = {{{b}}}'


def main() -> None:
    """Print the candidates, the distances to two targets, and the example where ignoring the swap overstates."""
    cands = candidates()
    print('candidates (bus A | bus B):')
    for k, cand in enumerate(cands):
        print(f'  {k}: {describe(cand)}')
    target = np.array([False, False, False, True, True, True])  # L3, L4, L5 on bus B
    print('target: L3 L4 L5 on bus B')
    print('  with swap   ', reassignment_distance(cands, target))
    print('  without swap', reassignment_distance(cands, target, allow_swap=False))
    mirror = ~target  # the same split, with the names of the two buses exchanged
    print('mirror target: L0 L1 L2 on bus B')
    print('  with swap   ', reassignment_distance(cands, mirror))
    print('  without swap', reassignment_distance(cands, mirror, allow_swap=False))


if __name__ == '__main__':
    main()

    four_substations.py
    """Voltage levels and switches of pypowsybl's four-substations node-breaker network (Chapter 13, Exercise 5).

Every voltage level of this example is modelled node-breaker, so each one has a list of switches with a kind
(``BREAKER`` or ``DISCONNECTOR``), an open flag and the two nodes it joins. In the bay of an asset, the breaker
interrupts current and the busbar disconnectors select the busbar; in a double-busbar level the coupler is a breaker
between the two busbar sections, with a disconnector on each side.
"""

import pandas as pd
import pypowsybl as pp

VOLTAGE_LEVEL = 'S1VL2'  # the only double-busbar level of the example: two busbar sections and a coupler


def network() -> pp.network.Network:
    """The four-substations node-breaker example shipped with pypowsybl."""
    return pp.network.create_four_substations_node_breaker_network()


def voltage_levels(net: pp.network.Network) -> pd.DataFrame:
    """Id, substation, nominal voltage and topology kind of every voltage level."""
    return net.get_voltage_levels(attributes=['substation_id', 'nominal_v', 'topology_kind'])


def switch_counts(net: pp.network.Network) -> pd.DataFrame:
    """Number of switches per voltage level and kind."""
    return net.get_switches().groupby(['voltage_level_id', 'kind']).size().unstack(fill_value=0)


def classify_switches(net: pp.network.Network, voltage_level: str = VOLTAGE_LEVEL) -> pd.DataFrame:
    """The switches of one voltage level with a ``role`` column.

    Roles: ``coupler`` (the breaker between the two busbar sections), ``coupler disconnector`` (its busbar
    selectors), ``bay breaker`` (the breaker of an asset bay) and ``busbar disconnector`` (the selector of an asset
    bay onto one busbar section). The role follows from the kind and from the node the switch touches: a switch
    touching a busbar-section node is a selector.
    """
    topo = net.get_node_breaker_topology(voltage_level)
    busbar_nodes = set(topo.nodes.index[topo.nodes['connectable_type'] == 'BUSBAR_SECTION'])
    switches = topo.switches.copy()
    on_busbar = switches['node1'].isin(busbar_nodes) | switches['node2'].isin(busbar_nodes)
    is_coupler = switches.index.str.contains('COUPLER')
    role = pd.Series('bay breaker', index=switches.index)
    role[(switches['kind'] == 'DISCONNECTOR') & on_busbar & ~is_coupler] = 'busbar disconnector'
    role[(switches['kind'] == 'DISCONNECTOR') & is_coupler] = 'coupler disconnector'
    role[(switches['kind'] == 'BREAKER') & is_coupler] = 'coupler'
    return switches.assign(role=role)


def main() -> None:
    """Print the voltage levels, the switch counts and the classification of the switches of S1VL2."""
    pd.set_option('display.width', 119)
    net = network()
    print(voltage_levels(net))
    print()
    print(switch_counts(net))
    print()
    classified = classify_switches(net)
    print(classified[['kind', 'open', 'retained', 'node1', 'node2', 'role']])
    print()
    print(classified.groupby(['kind', 'role']).size())


if __name__ == '__main__':
    main()
