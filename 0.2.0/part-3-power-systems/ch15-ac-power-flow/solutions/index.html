    Solutions of the Lab and the Exercises of Chapter 15. Try each task before reading its solution. The code is in the chapter's src folder: ac_jacobian.py (the Jacobian blocks of the worked example), nr_power_flow.py (the five-bus Newton–Raphson of the Lab, steps 1–4), powsybl_slack.py (Lab step 5 and Exercise 6), two_bus.py (Exercises 1 and 2), jacobian_timing.py (Exercise 3) and pf_algorithms.m (Exercise 4, Octave + MATPOWER).     Lab¶

    1. Newton–Raphson for a five-bus grid. CASE5 is a five-bus grid in MATPOWER column order: slack bus 1 at 1.06 pu, PV bus 2 at 1.045 pu generating 40 MW, loads 20 + j10, 45 + j15, 40 + j5 and 60 + j10 MVA at buses 2 to 5, and seven lines with \(r/x = 1/3\) and line charging. make_ybus builds \(Y_\text{bus}\) from the branch table (series admittance, half the charging at each end, taps and bus shunts), specified returns the bus types and the injections \(P^\text{spec}, Q^\text{spec}\) in pu, and newton_pf iterates with the four blocks of ac_jacobian.jacobian_blocks, keeping the \(P\) rows of the non-slack buses and the \(Q\) rows of the PQ buses. From a flat start the mismatch infinity norm goes \(4.9 \times 10^{-1} \to 3.3 \times 10^{-2} \to 7.2 \times 10^{-5} \to 5.1 \times 10^{-10}\) pu: the exponent doubles at each step, which is the quadratic convergence of Chapter 6. Three iterations reach \(10^{-8}\). The solution is \(\theta = (0, -2.768, -4.977, -5.309, -6.129)^\circ\) and \(|V| = (1.06, 1.045, 1.0223, 1.0215, 1.0156)\) pu. On a log scale the four points lie on a curve that bends down, not on a straight line: a straight line would be linear convergence.

      nr_power_flow.py
      """Newton-Raphson power flow of a five-bus grid, its failure modes and its initializations (Chapter 15, Lab 1-4).

The grid is a MATPOWER-style case dict (``CASE5``), so the same data feed the Newton-Raphson solver of this module,
``pandapower`` (through ``pandapower.converter.from_ppc``) and, saved as a case file, MATPOWER's ``runpf``.
Column indices follow the MATPOWER manual: bus table (bus number, type, Pd, Qd, Gs, Bs, ..., Vm), branch table
(from, to, r, x, b, ..., ratio, angle, status), generator table (bus, Pg, Qg, Qmax, Qmin, Vg, ...).
"""

import numpy as np
import pandapower as pp
from ac_jacobian import injections, jacobian_blocks

PQ, PV, SLACK = 1, 2, 3

def make_ybus(ppc: dict) -> np.ndarray:
    """Dense bus admittance matrix (pu) of a case dict: series branches, line charging, taps and bus shunts."""
    n = len(ppc['bus'])
    y = np.zeros((n, n), dtype=complex)
    for f, t, r, x, b, *_rest, ratio, angle, status in ppc['branch'][:, :11]:
        if not status:
            continue
        i, k = int(f) - 1, int(t) - 1
        ys = 1 / (r + 1j * x)
        tap = (ratio if ratio else 1.0) * np.exp(1j * np.deg2rad(angle))
        y[i, i] += (ys + 1j * b / 2) / abs(tap) ** 2
        y[k, k] += ys + 1j * b / 2
        y[i, k] -= ys / np.conj(tap)
        y[k, i] -= ys / tap
    y[np.diag_indices(n)] += (ppc['bus'][:, 4] + 1j * ppc['bus'][:, 5]) / ppc['baseMVA']
    return y


def specified(ppc: dict) -> tuple[np.ndarray, np.ndarray, np.ndarray, np.ndarray]:
    """Bus types, specified injections P and Q (pu, generation minus load) and the voltage set points."""
    bus, gen = ppc['bus'], ppc['gen']
    types = bus[:, 1].astype(int)
    p = -bus[:, 2] / ppc['baseMVA']
    q = -bus[:, 3] / ppc['baseMVA']
    vset = np.ones(len(bus))
    for g in gen[gen[:, 7] > 0]:
        i = int(g[0]) - 1
        p[i] += g[1] / ppc['baseMVA']
        q[i] += g[2] / ppc['baseMVA']
        vset[i] = g[5]
    return types, p, q, vset


def newton_pf(
    ybus: np.ndarray,
    types: np.ndarray,
    p_spec: np.ndarray,
    q_spec: np.ndarray,
    theta0: np.ndarray,
    vm0: np.ndarray,
    tol: float = 1e-8,
    max_iter: int = 20,
) -> tuple[np.ndarray, np.ndarray, list[float], bool]:
    """Polar Newton-Raphson: angles, magnitudes, the mismatch infinity norm per iteration and a converged flag.

    Unknowns are the angles of the non-slack buses and the magnitudes of the PQ buses; the Jacobian blocks come
    from ``ac_jacobian.jacobian_blocks``. The history has one entry per evaluated mismatch, the first one at the
    starting point. A singular Jacobian (an island without a slack) raises ``numpy.linalg.LinAlgError``.
    """
    theta, vm = theta0.astype(float).copy(), vm0.astype(float).copy()
    non_slack = np.flatnonzero(types != SLACK)
    pq = np.flatnonzero(types == PQ)
    history = []
    for _ in range(max_iter):
        s = injections(theta, vm, ybus)
        mismatch = np.concatenate([(p_spec - s.real)[non_slack], (q_spec - s.imag)[pq]])
        history.append(float(np.abs(mismatch).max()))
        if history[-1] < tol:
            return theta, vm, history, True
        j11, j12, j21, j22 = jacobian_blocks(theta, vm, ybus)
        jac = np.block(
            [
                [j11[np.ix_(non_slack, non_slack)], j12[np.ix_(non_slack, pq)]],
                [j21[np.ix_(pq, non_slack)], j22[np.ix_(pq, pq)]],
            ]
        )
        step = np.linalg.solve(jac, mismatch)
        theta[non_slack] += step[: len(non_slack)]
        vm[pq] += step[len(non_slack) :]
    return theta, vm, history, False


def flat_start(ppc: dict) -> tuple[np.ndarray, np.ndarray]:
    """Zero angles, set-point magnitudes at the slack and PV buses, 1 pu at the PQ buses."""
    types, _, _, vset = specified(ppc)
    vm = np.where(types == PQ, 1.0, vset)
    return np.zeros(len(types)), vm


def dc_start(ppc: dict) -> tuple[np.ndarray, np.ndarray]:
    """Angles of the DC power flow (b = 1/x, slack angle 0) with the magnitudes of the flat start."""
    types, p, _, _ = specified(ppc)
    n = len(types)
    bbus = np.zeros((n, n))
    for f, t, _r, x in ppc['branch'][:, :4]:
        i, k = int(f) - 1, int(t) - 1
        bbus[[i, k], [i, k]] += 1 / x
        bbus[[i, k], [k, i]] -= 1 / x
    keep = types != SLACK
    theta = np.zeros(n)
    theta[keep] = np.linalg.solve(bbus[np.ix_(keep, keep)], p[keep])
    return theta, flat_start(ppc)[1]


def solve(
    ppc: dict, start: tuple[np.ndarray, np.ndarray] | None = None, **kwargs
) -> tuple[np.ndarray, np.ndarray, list[float], bool]:
    """Newton-Raphson on a case dict from ``start`` (default: flat start)."""
    types, p, q, _ = specified(ppc)
    theta0, vm0 = start if start is not None else flat_start(ppc)
    return newton_pf(make_ybus(ppc), types, p, q, theta0, vm0, **kwargs)


def scaled_loads(ppc: dict, factor: float) -> dict:
    """A copy of the case with every load (P and Q) multiplied by ``factor``."""
    out = {k: (v.copy() if isinstance(v, np.ndarray) else v) for k, v in ppc.items()}
    out['bus'][:, 2:4] *= factor
    return out


def without_branches(ppc: dict, rows: list[int]) -> dict:
    """A copy of the case with the branches in ``rows`` (0-based) removed."""
    out = {k: (v.copy() if isinstance(v, np.ndarray) else v) for k, v in ppc.items()}
    out['branch'] = np.delete(out['branch'], rows, axis=0)
    return out


def pv_to_pq(ppc: dict, bus: int) -> dict:
    """A copy of the case where the generator at ``bus`` (1-based) no longer holds its voltage: Qg is fixed at 0."""
    out = {k: (v.copy() if isinstance(v, np.ndarray) else v) for k, v in ppc.items()}
    out['bus'][bus - 1, 1] = PQ
    return out


def pandapower_net(ppc: dict, f_hz: float = 50.0) -> pp.pandapowerNet:
    """The same case as a pandapower network: per-unit branch data become ohms and nF on the bus voltage base."""
    net = pp.create_empty_network(sn_mva=ppc['baseMVA'], f_hz=f_hz)
    for bus_i, _type, pd, qd, *_rest in ppc['bus']:
        b = pp.create_bus(net, vn_kv=ppc['bus'][int(bus_i) - 1, 9], index=int(bus_i) - 1)
        if pd or qd:
            pp.create_load(net, b, p_mw=pd, q_mvar=qd)
    types = ppc['bus'][:, 1].astype(int)
    for g in ppc['gen'][ppc['gen'][:, 7] > 0]:
        bus = int(g[0]) - 1
        if types[bus] == SLACK:
            pp.create_ext_grid(net, bus, vm_pu=g[5])
        elif types[bus] == PV:
            pp.create_gen(net, bus, p_mw=g[1], vm_pu=g[5])
        else:
            pp.create_sgen(net, bus, p_mw=g[1], q_mvar=g[2])
    for f, t, r, x, b, *_rest in ppc['branch']:
        z_base = ppc['bus'][int(f) - 1, 9] ** 2 / ppc['baseMVA']  # ohm
        c_nf = b / z_base / (2 * np.pi * f_hz) * 1e9
        pp.create_line_from_parameters(
            net,
            int(f) - 1,
            int(t) - 1,
            length_km=1.0,
            r_ohm_per_km=r * z_base,
            x_ohm_per_km=x * z_base,
            c_nf_per_km=c_nf,
            max_i_ka=1.0,
        )
    return net


def pandapower_solution(ppc: dict) -> tuple[np.ndarray, np.ndarray]:
    """Voltage angles (rad) and magnitudes (pu) of ``pandapower.runpp`` on the same case."""
    net = pandapower_net(ppc)
    pp.runpp(net, tolerance_mva=1e-10, init='flat')
    return np.deg2rad(net.res_bus.va_degree.to_numpy()), net.res_bus.vm_pu.to_numpy()


def max_loading(ppc: dict, step: float = 0.05, limit: float = 10.0) -> float:
    """The largest load multiple (in steps of ``step``) for which Newton-Raphson from a flat start converges."""
    factor = 1.0
    while factor + step <= limit and solve(scaled_loads(ppc, factor + step))[3]:
        factor += step
    return factor

    th_pp, vm_pp = pandapower_solution(CASE5)
    dv, dth = np.abs(vm - vm_pp).max(), np.rad2deg(np.abs(theta - th_pp)).max()
    print(f'Step 2: pandapower  max |dV| = {dv:.1e} pu, max |dtheta| = {dth:.1e} deg')
    lam = max_loading(CASE5)

      Open the src/ folder on GitHub to see or download all the files of this chapter.

    2. pandapower on the same data. pandapower_net builds the same grid with create_line_from_parameters: the per-unit branch data become ohms through \(Z_\text{base} = V_\text{base}^2 / S_\text{base} = 230^2/100 = 529\ \Omega\), and the line charging \(b\) becomes a capacitance \(C = b / (Z_\text{base}\, 2\pi f)\) in nF. runpp with tolerance_mva=1e-10 agrees with step 1 to \(5.5 \times 10^{-11}\) pu in magnitude and \(1.3 \times 10^{-9}\) degrees in angle; test_nr_power_flow.py also checks that make_ybus equals pandapower's internal Ybus entry by entry. With Octave, save CASE5 as a case file and call matpower_pf (worked example) on it; the voltages must agree to the same precision (not run here).

    3. Breaking convergence. Three failures, three signatures:
      • Loads scaled up (max_loading): with every load multiplied by 5.20 the iteration still converges, in 7 iterations, with the lowest voltage at 0.643 pu. At 5.25 it never does: the mismatch falls from 3.0 to \(8.7 \times 10^{-3}\) in five iterations and then wanders between \(10^{-2}\) and \(10^{-1}\) for the remaining fifteen, with \(|V| = (1.06, 1.045, 0.618, 0.622, 0.578)\) at iteration 20. This is the nose of the P–V curve: beyond the maximum loadability the equations have no solution, so Newton has nothing to converge to and the iterates oscillate around the point where the two solution branches merged. The Jacobian becomes singular exactly at the nose (Exercise 2).
      • A reactive source removed (pv_to_pq(CASE5, 2)): the generator at bus 2 no longer holds 1.045 pu and injects \(Q = 0\). The nominal case still converges (4 iterations, \(|V_2| = 1.032\) pu), but the largest load multiple drops from 5.20 to 2.95. Symptom: convergence on light load with low voltages and an earlier nose; near the limit the \(Q\) rows of the mismatch dominate.
      • An islanded load (without_branches(CASE5, [4, 6]), lines 2–5 and 4–5 removed): bus 5 keeps its load but has no path to a voltage source. The rows and columns of bus 5 in the reduced Jacobian are zero, so numpy.linalg.solve raises LinAlgError: Singular matrix at the first iteration. Symptom: no history at all, a singular or ill-conditioned matrix. Production solvers detect islands first (Chapter 3) and either drop them or give each one a slack.
    4. Initializations. On the case with the loads scaled by 5.20, the flat start and the DC-angle start both need 7 iterations, and the solution of the case scaled by 5.10 needs 4. All three end at the same voltages, \(|V| = (1.06, 1.045, 0.6696, 0.6741, 0.6427)\) pu. Here the DC angles do not help, because the angles are not the problem (they stay below 30°): it is the voltage magnitudes, which the DC start leaves at 1 pu, that are far from the 0.64–0.67 pu solution. A previous solution gets both right and halves the work. On a heavily loaded case there is a second, low-voltage solution of the same equations; a start below the nose would converge to it, which is why PREVIOUS_VALUES and DC_VALUES are tried in order on import (find_converging_loadflow_params).

    5. Distributed slack with pypowsybl. On the stock IEEE 14 nothing changes between Parameters(distributed_slack=False) and True: the generator targets (232.4 + 40 MW) already include the 13.4 MW of losses, so the remaining slack mismatch is \(-0.007\) MW and there is nothing to distribute. With every load raised by 10 % (compare(1.1)) the picture is:

      Generator (target) single slack proportional to P proportional to Pmax
      B1-G (232.4 MW) 232.4 257.27 246.97
      B2-G (40 MW) 40.0 44.28 54.57
      B3-G, B6-G, B8-G (0 MW) 0 0 0
      slack mismatch left 29.15 MW \(-0.27\) MW \(-0.91\) MW
      largest flow change vs single slack – 3.8 MW (L1-2) 12.9 MW (L1-2)

      With a single slack OpenLoadFlow leaves the 29.1 MW on the slack bus and reports it as slack_bus_results[0].active_power_mismatch; the slack generator's p keeps its target. With the slack distributed, the 29.1 MW go to the generators in the ratio 232.4 : 40 (PROPORTIONAL_TO_GENERATION_P) or equally (PROPORTIONAL_TO_GENERATION_P_MAX, both units have max_p = 9999 MW); the three synchronous condensers with a 0 MW target never participate. The largest base-case flow, on line 1–2, is 177.4 MW with a single slack, 173.6 MW and 164.5 MW with the two distributed settings: how the losses are shared changes the flows by up to 13 MW on a 260 MW system, which is the AC–DC mismatch argument of ToOp's loadflow_parameters.md.

      powsybl_slack.py
      """Single versus distributed slack on IEEE 14 with pypowsybl (Chapter 15, Lab step 5 and Exercise 6).

pypowsybl reports a generator's active power with the receptor sign convention (negative when generating), so
the module negates it to print MW produced. Branch flows ``p1`` are the active power entering at side 1.
"""

import pandas as pd
import pypowsybl as pyp
import pypowsybl.loadflow as lf

BALANCE = {
    'single slack': lf.Parameters(distributed_slack=False),
    'proportional to P': lf.Parameters(
        distributed_slack=True, balance_type=lf.BalanceType.PROPORTIONAL_TO_GENERATION_P
    ),
    'proportional to Pmax': lf.Parameters(
        distributed_slack=True, balance_type=lf.BalanceType.PROPORTIONAL_TO_GENERATION_P_MAX
    ),
}


def solve_ieee14(parameters: lf.Parameters, load_factor: float = 1.0) -> tuple[pd.Series, pd.Series, float]:
    """Generator outputs (MW), branch flows ``p1`` (MW) and the remaining slack mismatch of an AC load flow.

    The stock case is balanced (the generator targets already include the losses), so ``load_factor`` scales every
    load to create a mismatch for the slack to absorb.
    """
    net = pyp.network.create_ieee14()
    loads = net.get_loads()
    net.update_loads(id=loads.index, p0=loads['p0'] * load_factor, q0=loads['q0'] * load_factor)
    result = lf.run_ac(net, parameters)[0]
    if result.status != lf.ComponentStatus.CONVERGED:
        raise RuntimeError(f'load flow did not converge: {result.status}')
    gens = -net.get_generators()['p']
    flows = pd.concat([net.get_lines()['p1'], net.get_2_windings_transformers()['p1']])
    return gens, flows, result.slack_bus_results[0].active_power_mismatch


def compare(load_factor: float = 1.0, cases: dict[str, lf.Parameters] = BALANCE) -> tuple[pd.DataFrame, pd.DataFrame]:
    """Generator outputs and the five largest base-case branch flows, one column per slack setting."""
    gens, flows = {}, {}
    for name, parameters in cases.items():
        gens[name], flows[name], _ = solve_ieee14(parameters, load_factor)
    gens, flows = pd.DataFrame(gens), pd.DataFrame(flows)
    top = flows.abs().max(axis=1).nlargest(5).index
    return gens, flows.loc[top]


def main() -> None:
    """Print the tables of Lab step 5 and Exercise 6."""
    pd.set_option('display.width', 120)

        print(gens.round(3))
        print('total generation (MW):', gens.drop(columns='target_p').sum().round(3).to_dict())
        print('five largest base-case flows p1 (MW)')

    Exercise 1¶

    With \(V_1 = 1\angle 0\), \(V_2 = v\angle\delta\) and \(Y_\text{bus} = \begin{bmatrix} -j/X & j/X \\ j/X & -j/X \end{bmatrix}\) (\(G = 0\), \(B_{21} = 1/X\), \(B_{22} = -1/X\)), the injections at bus 2 from the general formulas of the worked example are

    \[ P_2 = \frac{v}{X}\sin\delta, \qquad Q_2 = \frac{v^2 - v\cos\delta}{X}, \]

    and the specified values are \(P_2^\text{spec} = -P\), \(Q_2^\text{spec} = -Q\) (a load). The Jacobian is

    \[ J = \begin{bmatrix} \partial P_2/\partial\delta & \partial P_2/\partial v \\ \partial Q_2/\partial\delta & \partial Q_2/\partial v \end{bmatrix} = \frac{1}{X}\begin{bmatrix} v\cos\delta & \sin\delta \\ v\sin\delta & 2v - \cos\delta \end{bmatrix}. \]

    Flat start \(\delta = 0\), \(v = 1\), with \(X = 0.1\), \(P = 1\), \(Q = 0.5\):

    • Iteration 1. \(P_2 = Q_2 = 0\), mismatch \((-1, -0.5)\), \(J = \operatorname{diag}(10, 10)\), step \((-0.1, -0.05)\): \(\delta = -0.1\) rad (\(-5.730^\circ\)), \(v = 0.95\).
    • Iteration 2. \(P_2 = 9.5\sin(-0.1) = -0.9484\), \(Q_2 = (0.9025 - 0.95\cos 0.1)/0.1 = -0.4275\), mismatch \((-0.0516, -0.0725)\), \(J = \begin{bmatrix} 9.4525 & -0.9983 \\ -0.9484 & 9.0500 \end{bmatrix}\), step \((-0.0064, -0.0087)\): \(\delta = -0.1064\) rad (\(-6.095^\circ\)), \(v = 0.9413\).

    The exact solution, from \(v^4 + (2QX - 1)v^2 + X^2(P^2 + Q^2) = 0\) (exact_solution), is \(v = 0.9412\), \(\delta = -0.1064\) rad (\(-6.099^\circ\)): two iterations are within \(10^{-4}\).     two_bus.py
    """Two-bus power flow: Newton-Raphson by hand and the power transfer curve (Chapter 15, Exercises 1 and 2).

Slack bus 1 at 1 pu and zero angle, PQ bus 2 with load P + jQ behind a lossless line of reactance X. With
v = |V2| and d = theta_2, the injections at bus 2 are P2 = (v / X) sin d and Q2 = (v² - v cos d) / X, and the
specified values are -P and -Q (a load), so the solution has d < 0.
"""

import numpy as np


def injections_2bus(d: float, v: float, x: float) -> np.ndarray:
    """(P2, Q2) at the load bus for angle ``d`` (rad), magnitude ``v`` and line reactance ``x``."""
    return np.array([v * np.sin(d) / x, (v**2 - v * np.cos(d)) / x])


def jacobian_2bus(d: float, v: float, x: float) -> np.ndarray:
    """The 2 x 2 Jacobian [[dP2/dd, dP2/dv], [dQ2/dd, dQ2/dv]]."""
    return np.array([[v * np.cos(d) / x, np.sin(d) / x], [v * np.sin(d) / x, (2 * v - np.cos(d)) / x]])


def newton_steps(p: float, q: float, x: float, n_steps: int = 2) -> list[dict]:
    """The first ``n_steps`` Newton iterations from the flat start, with mismatch, Jacobian, step and new state."""
    d, v = 0.0, 1.0
    out = []
    for _ in range(n_steps):
        mismatch = np.array([-p, -q]) - injections_2bus(d, v, x)
        jac = jacobian_2bus(d, v, x)
        step = np.linalg.solve(jac, mismatch)
        d, v = d + step[0], v + step[1]
        out.append({'mismatch': mismatch, 'jacobian': jac, 'step': step, 'state': np.array([d, v])})
    return out


def exact_solution(p: float, q: float, x: float) -> tuple[float, float]:
    """Closed form (angle in rad, magnitude): the high-voltage root of v⁴ + (2QX - 1) v² + X²(P² + Q²) = 0."""
    b = 2 * q * x - 1
    c = x**2 * (p**2 + q**2)
    v = np.sqrt((-b + np.sqrt(b**2 - 4 * c)) / 2)
    return float(-np.arcsin(p * x / v)), float(v)


def transfer(v1: float, v2: float, x: float, delta: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
    """P = |V1||V2| sin(delta) / X and Q2 = (|V1||V2| cos(delta) - |V2|²) / X for the angles ``delta`` (rad)."""
    return v1 * v2 * np.sin(delta) / x, (v1 * v2 * np.cos(delta) - v2**2) / x


def main() -> None:
    """Exercise 1 (two iterations, exact solution) and Exercise 2 (maximum transfer, Jacobian at 90 degrees)."""
    x, p, q = 0.1, 1.0, 0.5
    for k, it in enumerate(newton_steps(p, q, x), start=1):
        print(
            f'iteration {k}: mismatch {np.round(it["mismatch"], 4)}, Jacobian {np.round(it["jacobian"], 4).tolist()}'
        )
        d, v = it['state']
        print(f'  step {np.round(it["step"], 4)} -> theta2 = {d:.4f} rad ({np.rad2deg(d):.3f} deg), |V2| = {v:.4f}')
    d, v = exact_solution(p, q, x)
    print(f'exact: theta2 = {d:.4f} rad ({np.rad2deg(d):.3f} deg), |V2| = {v:.4f}')
    more = newton_steps(p, q, x, 5)
    print('mismatch inf-norm per iteration:', ' '.join(f'{np.abs(it["mismatch"]).max():.1e}' for it in more))
    delta = np.deg2rad(np.linspace(0, 90, 7))
    pt, qt = transfer(1.0, 1.0, x, delta)
    print('delta (deg):', np.round(np.rad2deg(delta)).astype(int), ' P:', np.round(pt, 3), ' Q2:', np.round(qt, 3))
    for deg in (60, 85, 89, 90):
        print(f'dP/d(delta) at {deg} deg: {np.cos(np.deg2rad(deg)) / x:.4f} pu/rad')


if __name__ == '__main__':
    main()

    jacobian_timing.case_state takes the converged state and the sparse Ybus of pandapower's case14 and case118 (from net._ppc['internal']). finite_difference_error compares every column of the four blocks with central differences of injections (\(h = 10^{-6}\)): the largest difference is \(7.7 \times 10^{-9}\) on IEEE 14 and \(2.5 \times 10^{-8}\) on IEEE 118, the round-off level of a central difference, so the formulas are right. jacobian_blocks_sparse is the same matrix expression with scipy.sparse.diags and a CSR Ybus.     jacobian_timing.py
    """Polar Jacobian of IEEE 14 and IEEE 118 against finite differences; dense versus sparse (Chapter 15, Exercise 3).

The bus admittance matrix comes from pandapower's internal ``Ybus`` after ``runpp``; the state is the converged
one, read from the same internal structure.
"""

import timeit

import numpy as np
import pandapower as pp
import pandapower.networks as pn
import scipy.sparse as sps
from ac_jacobian import injections, jacobian_blocks


def case_state(name: str) -> tuple[np.ndarray, np.ndarray, sps.csr_matrix]:
    """Converged angles (rad), magnitudes (pu) and the sparse Ybus (pu) of a pandapower network case."""
    net = getattr(pn, name)()
    pp.runpp(net)
    v = np.asarray(net._ppc['internal']['V'])
    return np.angle(v), np.abs(v), sps.csr_matrix(net._ppc['internal']['Ybus'])


def jacobian_blocks_sparse(theta: np.ndarray, vm: np.ndarray, y: sps.spmatrix) -> tuple[sps.csr_matrix, ...]:
    """The same four blocks as ``ac_jacobian.jacobian_blocks``, with sparse diagonals and a sparse Ybus."""
    v = vm * np.exp(1j * theta)
    i = y @ v
    diag_v, diag_i, e = sps.diags(v), sps.diags(i), sps.diags(v / vm)
    ds_dth = 1j * diag_v @ (diag_i - y @ diag_v).conj()
    ds_dvm = diag_v @ (y @ e).conj() + diag_i.conj() @ e
    return ds_dth.real.tocsr(), ds_dvm.real.tocsr(), ds_dth.imag.tocsr(), ds_dvm.imag.tocsr()


def finite_difference_error(theta: np.ndarray, vm: np.ndarray, y: np.ndarray, h: float = 1e-6) -> float:
    """Largest difference between the analytic blocks and central differences of ``injections``, column by column."""
    j11, j12, j21, j22 = jacobian_blocks(theta, vm, y)
    n = len(theta)
    worst = 0.0
    for k in range(n):
        d = np.zeros(n)
        d[k] = h
        ds = (injections(theta + d, vm, y) - injections(theta - d, vm, y)) / (2 * h)
        worst = max(worst, np.abs(j11[:, k] - ds.real).max(), np.abs(j21[:, k] - ds.imag).max())
        ds = (injections(theta, vm + d, y) - injections(theta, vm - d, y)) / (2 * h)
        worst = max(worst, np.abs(j12[:, k] - ds.real).max(), np.abs(j22[:, k] - ds.imag).max())
    return worst


def time_both(theta: np.ndarray, vm: np.ndarray, y: sps.csr_matrix, number: int = 50) -> tuple[float, float]:
    """Milliseconds per evaluation of the dense and of the sparse Jacobian blocks (best of three runs)."""
    y_dense = y.toarray()
    dense = min(timeit.repeat(lambda: jacobian_blocks(theta, vm, y_dense), number=number, repeat=3)) / number
    sparse = min(timeit.repeat(lambda: jacobian_blocks_sparse(theta, vm, y), number=number, repeat=3)) / number
    return 1e3 * dense, 1e3 * sparse


def main() -> None:
    """Finite-difference error and timings for IEEE 14 and IEEE 118."""
    for name in ('case14', 'case118'):
        theta, vm, y = case_state(name)
        err = finite_difference_error(theta, vm, y.toarray())
        dense, sparse = time_both(theta, vm, y)
        print(f'{name}: {len(theta)} buses, {y.nnz} nonzeros in Ybus, max |analytic - central difference| = {err:.1e}')
        print(f'  dense blocks {dense:.3f} ms, sparse blocks {sparse:.3f} ms per evaluation')


if __name__ == '__main__':
    main()

    Case NR FDXB GS
    case14 2 iterations, 0.098 s 6 iterations, 0.184 s 103 iterations, 0.355 s
    case118 3 iterations, 0.120 s 8 iterations, 0.195 s 2111 iterations, 10.4 s

    Gauss–Seidel needs pf.gs.max_it raised to 5000 on case118 (2111 iterations are more than the default limit). The ranking follows from the cost per iteration against the number of iterations. Newton–Raphson converges quadratically (2–3 iterations) but each iteration builds the Jacobian and factorizes a new \((2n - n_{PV} - 2)\) matrix. The fast decoupled method factorizes \(B'\) and \(B''\) once, then does two cheap forward–backward substitutions per iteration, but its convergence is linear (the decoupling \(\partial P/\partial|V| \approx 0\), \(\partial Q/\partial\theta \approx 0\) is an approximation of the Jacobian), hence 6–8 iterations. Gauss–Seidel costs one sweep through the buses per iteration, no factorization at all, and converges linearly with a rate that worsens with the size of the system: 103 iterations on 14 buses, 2111 on 118. On small cases the wall time is dominated by MATPOWER's setup, which is why FDXB does not beat NR here; its advantage shows in repeated solves of large cases (contingency analysis), where the factorizations are reused.

    Exercise 5¶

    The DC power flow \(P = B_\text{bus}\theta\) is linear: for any connected topology (with the slack in the component) \(\tilde B\) is a nonsingular grounded Laplacian (Chapter 16), so there is exactly one solution for every injection vector, however large. The AC equations are nonlinear and have a solution only inside a bounded region of the injection space; outside it Newton–Raphson has nothing to find. Three physical causes, with the symptom each leaves in the mismatch history (all three appear in Lab step 3):

    1. Active power beyond the transfer limit. A corridor asked to carry more than \(|V_f||V_t|/X\) (Exercise 2), because a topology change lengthened the path or a line outage left one line with the load of two. The DC model happily reports a flow of 150 % of the limit; in AC the \(P\)–\(\delta\) curve has no point there. Symptom: the mismatch decreases for a few iterations, then stalls or oscillates around \(10^{-2}\)–\(10^{-1}\) while angles across the corridor approach 90° (Lab 3, loads × 5.25).
    2. Reactive power deficit, voltage collapse. Loads with reactive demand far from any voltage-controlled bus, after losing a generator, a shunt capacitor or a line that carried reactive support. The DC model ignores \(Q\) and fixes \(|V| = 1\), so it sees nothing. Symptom: the \(Q\) rows dominate the mismatch, the voltage magnitudes sink iteration after iteration (0.6 pu and below), PV buses hit their reactive limits and switch to PQ, sometimes flip-flopping between the two types; the limit of the loading comes much earlier than with the reactive source present (Lab 3, bus 2 without voltage control: 2.95 instead of 5.20).
    3. Topology or data that make the Jacobian singular or ill-conditioned. An island without a generator (the DC solve fails too, but only if the island is noticed), an island with generation but no slack, a branch with near-zero reactance, a wrong tap or a load entered in the wrong unit. Symptom: a singular-matrix error or a huge first step (voltages of 10 pu, angles of hundreds of degrees) followed by divergence, visible from the first iteration (Lab 3, bus 5 islanded). Note that ToOp's DC solver accepts the topology and the AC validation rejects it, which is what the "non-converging load flows" metric of the AC stage counts.
