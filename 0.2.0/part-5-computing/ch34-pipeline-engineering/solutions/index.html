    Chapter 34 – Solutions¶

    Solutions of the Lab and the Exercises of Chapter 34. Try each task before reading its solution. The code is in the chapter's src folder: mini_pipeline.py (the message-to-database hop with the standard library, runs anywhere), shm_fill.py (standard library, meant for the container) and six programs that need ToOp's interpreter, folder_contract_toop.py, fake_pipeline_toop.py, tensorboard_log_toop.py, tyro_flags_toop.py, hydra_sweep_toop.py and ray_store_toop.py. Every number below was printed by one of them (python <name>.py), with ToOp commit ba1874e on the CPU of the maintainer's Windows machine, not in the container, except in Exercise 5, which was run in the ToOp container and quotes docker run output there; the ToOp programs read ToOp's tracked data/ folders and write only to temporary folders. The worked examples run in examples.ipynb; the lab's notebook, lab_toop.ipynb, needs ToOp.

    Three things about ToOp ba1874e on Windows had to be worked around in the code, and are findings in their own right: dc/main.py names the TensorBoard folder str(datetime.datetime.now()), whose colons Windows rejects (WinError 123; tensorboard_log_toop.windows_safe_log_dir swaps that module's datetime for one that prints dashes, as the course fork's fix does); ga_helpers.update_running_means divides by the wall-clock time between epochs, which is zero when an epoch is shorter than the 15.6 ms tick of Python 3.11's time.time() on Windows (ZeroDivisionError; a larger iterations_per_epoch avoids it); and tyro's --help draws box characters that a cp1252 console cannot encode (PYTHONUTF8=1).

      So the folder is a contract between three stages: the importer fills it from the grid model, the preprocessing adds the solver's arrays and the action set, and the DC stage reads one file (static_information.hdf5) while the AC stage reads everything but that one. With h5py, static_information.hdf5 has 36 datasets and 14 attributes; the ptdf dataset is (82, 72) in float64, 82 branches by 72 buses (case57 has 57 buses, the node-breaker expansion adds the second busbars of the 12 relevant substations as n_stat, rel_stat_map and tot_stat describe). load_static_information gives the same shape and slack = 1.

    2. Messages without a broker. fake_pipeline_toop loads tests/fake_kafka.py by path, builds the StartOptimizationCommand of test_ac_dc_integration_sequential for the node-breaker grid (6 s of runtime, iterations_per_epoch=2, n_worst_contingencies=2), wraps serialize_message(command.model_dump_json()) in a FakeConsumer(..., kill_on_empty=True) and runs the DC worker main until FakeConsumerEmptyException. The worker writes nothing to the grid folder; the producer holds 97 heartbeats and 5 result messages, decoded with deserialize_message and Result.model_validate_json:

      Type Optimizer Timesteps Actions Fitness Reason
      OptimizationStartedResult dc 1 [] −61.445
      TopologyPushResult dc 1 [3] −57.058
      TopologyPushResult dc 1 [5] −42.345
      TopologyPushResult dc 1 [4] −57.058
      OptimizationStoppedResult dc converged

      value_counts: 3 pushes, 1 started, 1 stopped. The started message carries the unsplit topology (fitness −61.445, the initial overload energy of 61.4 MW); the three pushes are the repertoire's cells after 6 s. One detail of the lab: with the default n_worst_contingencies=20 the worker answers a single OptimizationStoppedResult with reason='error' and the message k argument to top_k must be no larger than minor dimension; 20 vs [8, 1, 11], because this grid has 11 N-1 cases; errors travel on the results topic like any other result (test_too_many_worst_contingencies_is_reported_as_an_error_result).

    3. The AC store. store_results creates the session and calls poll_results_topic(db=session, consumer=FakeConsumer({"results": ...})); select(ACOptimTopology) gives four rows with the columns disconnections, actions, timestep, optimization_id, fitness, worst_k_contingency_cases, stored_loadflow_reference, acceptance, id, pst_setpoints, unsplit, strategy_hash, optimizer_type, metrics, created_at, parent_id: one unsplit=True row from the started message and one per push, with worst_k_contingency_cases = ['generator3', 'L8'], optimizer_type = DC, acceptance = None (nothing has been validated yet) and a 32-byte strategy_hash. The finished_optimizations table has one row, lab34 / DC. scrub_db(session, max_age_seconds=0) leaves zero rows. A restart loses exactly what scrub_db removes: every DC candidate waiting for validation, every AC result (acceptance, the load-flow references), the parent links of the AC mutations and the list of finished optimizations, because create_session() opens sqlite://, an in-memory database with a StaticPool so that the worker's threads share one connection. The worker can only recover by re-reading the results topic from the beginning, which is why ToOp stores topologies from all optimizations and keeps a day of them.

    4. Logs. tensorboard_log_toop.run_stage runs run_dc_optimization_stage on the tracked static_information.hdf5 of the node-breaker grid for 12 s (500 iterations per epoch, see the Windows note above) into a temporary run folder: res.json, stats/ (180 files, res_<epoch>.json at every epoch since checkpoint_frequency is never read) and tensorboard/<timestamp>/events.out.tfevents.*. TensorBoard is not installed in ToOp's environment (tensorboard is an empty namespace next to tensorboardX), so the viewer step is not run here; read_scalars parses the event file (a TFRecord: uint64 length, CRC, serialized Event, CRC) and finds the tags fitness, overload_energy_n_1, split_subs and switching_distance, 159 points for fitness over 157 epochs. The series is -61.445 at step 0 (the initial topology), -42.345 from the first epoch on and never changes again: plateau_report gives last_improvement_epoch = 0 and a flat tail of 100 %. The run had plateaued almost at once, which on this grid is the truth rather than a symptom: the action set has 10 actions, and action 5 (the only one that helps) is found in the first 500 iterations. In TensorBoard the same picture is a step at epoch 0 followed by a horizontal line; the decision rule is the one of Chapter 26: stop when the best fitness has not moved for a budgeted number of epochs, and report that number with the result.

    Exercise 1¶

    poll_results_topic (optimizer/ac/listener.py) consumes one batch of up to 10 000 messages and handles three kinds: TopologyPushResult and OptimizationStartedResult are converted with convert_message_topo_to_db_topo and inserted one by one, counting added_topos[optimization_id] += 1 for every insert that does not raise IntegrityError; OptimizationStoppedResult is collected in finished_optimizations. After the loop, finish_optimization records each stopped optimization in finished_optimizations (for an AC stop it also deletes that optimization's topologies) and then the function does del added_topos[result.optimization_id]: the count of an optimization whose stop message is in the same batch is removed before returning. In the lab the whole DC run, started, three pushes and stopped, arrives in one consume call, so added is {} while four rows were stored (fake_pipeline_toop prints added={} finished=['lab34']; rows stored 4). The AC worker reads the returned dictionary as "optimizations with new work": a DC run that has already finished should not start AC work from this call, although its topologies stay in the table for an AC optimization that is picked up later. Had the DC run not finished, the stop message would be missing and the same call returns added={'lab34': 4} with finished=[] (the second print of the program). Replaying the same messages adds {} because every strategy hash is already in the table: the IntegrityError path is the deduplication. mini_pipeline.poll_results reproduces the three cases with sqlite3 alone.

    fake_pipeline_toop.py
    """Run ToOp's DC worker on an in-process fake broker and feed its results to the AC worker's store (Chapter 34).

Lab steps 2 and 3 and Exercise 1. Run with ToOp's interpreter from this folder::

    ../../../../../ToOp/.venv/Scripts/python.exe fake_pipeline_toop.py

The worker reads the tracked preprocessed folder ``data/grid_node_breaker/grid`` and writes nothing to it; the
results stay in the fake producer's memory and then in an in-memory SQLite database.
"""

import contextlib
import importlib.util
import os
from pathlib import Path

import pandas as pd
from fsspec.implementations.dirfs import DirFileSystem
from sqlmodel import select
from toop_engine_interfaces.messages.protobuf_message_factory import deserialize_message, serialize_message
from toop_engine_topology_optimizer.ac.listener import poll_results_topic
from toop_engine_topology_optimizer.ac.storage import ACOptimTopology, FinishedOptimizations, create_session, scrub_db
from toop_engine_topology_optimizer.dc.worker.worker import Args
from toop_engine_topology_optimizer.dc.worker.worker import main as dc_main
from toop_engine_topology_optimizer.interfaces.messages.ac_params import ACGAParameters, ACOptimizerParameters
from toop_engine_topology_optimizer.interfaces.messages.commands import Command, StartOptimizationCommand
from toop_engine_topology_optimizer.interfaces.messages.commons import Framework, GridFile
from toop_engine_topology_optimizer.interfaces.messages.dc_params import (
    BatchedMEParameters,
    DCOptimizerParameters,
    LoadflowSolverParameters,
)
from toop_engine_topology_optimizer.interfaces.messages.results import Result

TOOP = Path(os.environ.get('TOOP_REPO', Path(__file__).resolve().parents[4].parent / 'ToOp'))
GRID_ROOT = TOOP / 'data' / 'grid_node_breaker'  # the GridFile's grid_folder "grid" is relative to this root


def fake_kafka():
    """ToOp's ``tests/fake_kafka.py`` loaded by path (it is a test helper, not part of the installed packages)."""
    path = TOOP / 'packages' / 'topology_optimizer_pkg' / 'tests' / 'fake_kafka.py'
    spec = importlib.util.spec_from_file_location('fake_kafka', path)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module


def start_command(runtime_seconds=6.0, seed=42, n_worst_contingencies=2, optimization_id='lab34'):
    """The command a backend would publish on ``commands``; the node-breaker grid has 11 N-1 cases, so k <= 11."""
    return Command(
        command=StartOptimizationCommand(
            ac_params=ACOptimizerParameters(ga_config=ACGAParameters(runtime_seconds=runtime_seconds, seed=seed)),
            dc_params=DCOptimizerParameters(
                ga_config=BatchedMEParameters(
                    iterations_per_epoch=2,
                    runtime_seconds=runtime_seconds,
                    random_seed=seed,
                    n_worst_contingencies=n_worst_contingencies,
                ),
                loadflow_solver_config=LoadflowSolverParameters(batch_size=8),
            ),
            grid_files=[GridFile(framework=Framework.PYPOWSYBL, grid_folder='grid')],
            optimization_id=optimization_id,
        )
    )


def run_dc_worker(command, grid_root=GRID_ROOT):
    """Run ``dc_main`` until the fake consumer runs dry; returns the producer's messages per topic."""
    kafka = fake_kafka()
    consumer = kafka.FakeConsumer({'commands': [serialize_message(command.model_dump_json())]}, kill_on_empty=True)
    producer = kafka.FakeProducer()
    with contextlib.suppress(kafka.FakeConsumerEmptyException):
        dc_main(
            Args(
                optimizer_command_topic='commands',
                optimizer_heartbeat_topic='heartbeats',
                optimizer_results_topic='results',
            ),
            processed_gridfile_fs=DirFileSystem(str(grid_root)),
            producer=producer,
            command_consumer=consumer,
        )
    return producer.messages


def decode(messages):
    """Protobuf envelope -> JSON -> ``Result`` for every message of a topic."""
    return [Result.model_validate_json(deserialize_message(m)) for m in messages]


def message_table(messages):
    """One row per result message: type, optimizer, timesteps, first timestep's actions and fitness, stop reason."""
    rows = []
    for result in decode(messages):
        inner = result.result
        strategy = getattr(inner, 'strategy', None) or getattr(inner, 'initial_topology', None)
        first = strategy.timesteps[0] if strategy is not None else None
        rows.append(
            {
                'type': type(inner).__name__,
                'optimizer': result.optimizer_type.value,
                'optimization_id': result.optimization_id,
                'timesteps': len(strategy.timesteps) if strategy is not None else None,
                'actions': first.actions if first is not None else None,
                'fitness': first.metrics.fitness if first is not None else None,
                'reason': getattr(inner, 'reason', None),
            }
        )
    return pd.DataFrame(rows)


def store_results(messages, session=None):
    """Feed result messages to the AC store through ``poll_results_topic``; returns (session, added, finished)."""
    session = session or create_session()
    added, finished = poll_results_topic(db=session, consumer=fake_kafka().FakeConsumer({'results': list(messages)}))
    return session, added, finished


def topology_table(session):
    """The ``ac_optim_topology`` table as a data frame (the hash shown in hex)."""
    rows = [t.model_dump() for t in session.exec(select(ACOptimTopology)).all()]
    table = pd.DataFrame(rows)
    if not table.empty:
        table['strategy_hash'] = table['strategy_hash'].map(lambda h: h.hex()[:12])
    return table


def main():
    """Run the worker, tabulate the results, store them, answer Exercise 1 and scrub."""
    messages = run_dc_worker(start_command())
    print({topic: len(msgs) for topic, msgs in messages.items()})
    table = message_table(messages['results'])
    print(table.to_string(index=False))
    print(table['type'].value_counts().to_dict())
    session, added, finished = store_results(messages['results'])
    topos = topology_table(session)
    print(f'\nwith the stop message: added={added} finished={finished}; rows stored {len(topos)}')
    print('columns:', topos.columns.tolist())
    print(
        topos[
            ['id', 'actions', 'fitness', 'unsplit', 'optimizer_type', 'worst_k_contingency_cases', 'strategy_hash']
        ].to_string(index=False)
    )
    print('finished_optimizations:', [f.model_dump() for f in session.exec(select(FinishedOptimizations)).all()])
    session2, added2, finished2 = store_results(messages['results'][:-1])
    print(f'without the stop message: added={added2} finished={finished2}')
    _, added3, _ = store_results(messages['results'][:-1], session2)
    print(f'replaying the same messages: added={added3} (duplicates rejected by the unique strategy hash)')
    scrub_db(session, max_age_seconds=0)
    print('rows after scrub_db(max_age_seconds=0):', len(topology_table(session)))


if __name__ == '__main__':
    main()
    mini_pipeline.py
    """ToOp's message-to-database hop in sixty lines: a fake broker, a Pydantic result and a SQLite store (Chapter 34).

This is the shape of ``packages/topology_optimizer_pkg/tests/fake_kafka.py``, ``optimizer/ac/listener.py`` and
``optimizer/ac/storage.py`` with the standard library only, so that the mechanisms of the chapter run without ToOp:
a producer that keeps messages per topic, a consumer that replays them and raises when it runs dry, a store that
rejects duplicates through a unique hash and forgets old rows, and a poll function that returns the count of
rows added per optimization, minus the optimizations that have already stopped.
"""

import hashlib
import json
import sqlite3
import time
from typing import Literal

from pydantic import BaseModel


class Topology(BaseModel):
    """One candidate: the action indices and its fitness."""

    actions: list[int]
    fitness: float


class Result(BaseModel):
    """What travels on the ``results`` topic: a push, or a stopped notice."""

    optimization_id: str
    kind: Literal['started', 'push', 'stopped']
    topology: Topology | None = None


class FakeProducer:
    """Stores the bytes it would have sent, per topic."""

    def __init__(self):
        """Start with no topics."""
        self.messages: dict[str, list[bytes]] = {}

    def produce(self, topic, value):
        """Append ``value`` to ``topic``."""
        self.messages.setdefault(topic, []).append(value)


class FakeConsumerEmptyError(Exception):
    """Raised by a consumer with ``kill_on_empty`` once every topic has been read: the worker loop's exit."""


class FakeConsumer:
    """Replays stored messages; with ``kill_on_empty`` it raises instead of returning an empty batch."""

    def __init__(self, messages, kill_on_empty=False):
        """``messages`` maps topic to a list of bytes."""
        self.messages = messages
        self.offsets = dict.fromkeys(messages, 0)
        self.kill_on_empty = kill_on_empty

    def consume(self, num_messages=10_000):
        """The next messages, across topics, in order."""
        out = []
        for topic, msgs in self.messages.items():
            take = msgs[self.offsets[topic] : self.offsets[topic] + num_messages - len(out)]
            self.offsets[topic] += len(take)
            out.extend(take)
        if not out and self.kill_on_empty:
            raise FakeConsumerEmptyError('no more messages to consume')
        return out


def create_session():
    """An in-memory SQLite database with the topology table and a unique strategy hash, as ``create_session`` does."""
    db = sqlite3.connect(':memory:')
    db.execute(
        'CREATE TABLE topology (id INTEGER PRIMARY KEY, optimization_id TEXT, actions TEXT, fitness REAL, '
        'strategy_hash TEXT UNIQUE, created_at REAL)'
    )
    db.execute('CREATE TABLE finished (optimization_id TEXT PRIMARY KEY, finished_at REAL)')
    return db


def strategy_hash(topology):
    """The unique key of a topology: a hash of its actions, independent of the message that carried it."""
    return hashlib.sha256(json.dumps(sorted(topology.actions)).encode()).hexdigest()


def poll_results(db, consumer):
    """Store every pushed topology; return rows added per optimization and the optimizations that stopped.

    Duplicates raise ``IntegrityError`` on the unique hash and are skipped. Like ToOp's ``poll_results_topic``,
    the count of an optimization whose ``stopped`` message is in the same batch is deleted before returning.
    """
    added, stopped = {}, []
    for raw in consumer.consume():
        result = Result.model_validate_json(raw)
        if result.kind == 'stopped':
            stopped.append(result.optimization_id)
            db.execute('INSERT OR IGNORE INTO finished VALUES (?, ?)', (result.optimization_id, time.time()))
            continue
        if result.topology is None:
            continue
        try:
            db.execute(
                'INSERT INTO topology (optimization_id, actions, fitness, strategy_hash, created_at) '
                'VALUES (?, ?, ?, ?, ?)',
                (
                    result.optimization_id,
                    json.dumps(result.topology.actions),
                    result.topology.fitness,
                    strategy_hash(result.topology),
                    time.time(),
                ),
            )
            added[result.optimization_id] = added.get(result.optimization_id, 0) + 1
        except sqlite3.IntegrityError:
            pass
    for optimization_id in stopped:
        added.pop(optimization_id, None)
    return added, stopped


def scrub(db, max_age_seconds=86_400):
    """Delete topologies older than ``max_age_seconds`` (ToOp keeps one day)."""
    db.execute('DELETE FROM topology WHERE created_at < ?', (time.time() - max_age_seconds,))
    return db.execute('SELECT COUNT(*) FROM topology').fetchone()[0]


def dc_run(optimization_id='demo', topologies=((), (3,), (5,), (3,), (4,))):
    """A DC worker in miniature: one started message, one push per topology (with a repeat), one stopped message."""
    producer = FakeProducer()
    producer.produce('results', Result(optimization_id=optimization_id, kind='started').model_dump_json().encode())
    for i, actions in enumerate(topologies):
        topo = Topology(actions=list(actions), fitness=-60.0 + 5.0 * i)
        producer.produce(
            'results', Result(optimization_id=optimization_id, kind='push', topology=topo).model_dump_json().encode()
        )
    producer.produce('results', Result(optimization_id=optimization_id, kind='stopped').model_dump_json().encode())
    return producer


def main():
    """Run the miniature end to end and print what Exercise 1 asks about."""
    producer = dc_run()
    msgs = producer.messages['results']
    print(f'{len(msgs)} messages on "results":', [Result.model_validate_json(m).kind for m in msgs])
    db = create_session()
    print('with the stopped message   : added', *poll_results(db, FakeConsumer({'results': msgs})))
    print(
        'rows stored                :',
        db.execute('SELECT COUNT(*) FROM topology').fetchone()[0],
        '(one duplicate rejected)',
    )
    db2 = create_session()
    print('without the stopped message: added', *poll_results(db2, FakeConsumer({'results': msgs[:-1]})))
    print('replaying the same messages: added', *poll_results(db2, FakeConsumer({'results': msgs[:-1]})))
    print('rows after scrub(max_age_seconds=0):', scrub(db, 0))
    consumer = FakeConsumer({'results': msgs}, kill_on_empty=True)
    consumer.consume()
    try:
        consumer.consume()
    except FakeConsumerEmptyError as err:
        print('second consume() ->', type(err).__name__, err)
    db.close()
    db2.close()


if __name__ == '__main__':
    main()

    Exercise 2¶

    folder_contract_toop.field_mapping matches the 36 datasets of case57's static_information.hdf5 against the dataclass fields of DynamicInformation, ActionSet and SolverConfig (dc_solver/jax/types.py):

    • 20 datasets are DynamicInformation fields of the same name: ptdf (82, 72), from_node, to_node, susceptance (82,), nodal_injections (1, 72), unsplit_flow (1, 82), branches_monitored, branches_to_fail (81,), disconnectable_branches (27,), tot_stat and from_stat_bool (12, 6), generators_per_sub, relevant_injections (1, 12, 2), relevant_injection_outage_idx, relevant_injection_outage_sub, nonrel_injection_outage_node, nonrel_injection_outage_deltap;
    • 7 datasets prefixed action_set_ are the fields of DynamicInformation.action_set: branch_actions (127, 6), inj_actions (127, 2), n_actions_per_sub (12,), action_start_indices, substation_correspondence, reassignment_distance, unsplit_action_mask (127 actions over 12 relevant substations);
    • 6 datasets are built into other fields at load time: max_mw_flow, max_mw_flow_limited, max_mw_flow_n_1, max_mw_flow_n_1_limited, n0_n1_max_diff and overload_weight become DynamicInformation.branch_limits (a BranchLimits module), coupler_limits goes with them;
    • 5 datasets are SolverConfig values stored as datasets, not attributes: slack (a scalar, 1 here), n_stat, rel_stat_map (12,), branches_per_sub (12,) and contingency_ids (84,) (strings, which HDF5 attributes handle badly).

    The 14 attributes are the remaining SolverConfig values, all scalars that fix shapes or the aggregation: aggregation_metric = overload_energy_n_1, batch_size_bsdf = 16, batch_size_injection = 16, buffer_size_injection = 512, number_most_affected = 30, number_most_affected_n_0 = 30, number_max_out_in_most_affected = 5, the booleans enable_bb_outages, bb_outage_as_nminus1, clip_bb_outage_penalty, enable_parallel_pst_group_optim, distributed, plus two pieces of file metadata that are not solver configuration, format = jax and version = 0.0.0.post256.dev0+41be8d7 (the ToOp version that wrote this tracked file, older than ba1874e). The split follows from what JAX needs: the arrays are traced values and may differ between grids of the same shape; the attributes are the static part of the cache key (hash(solver_config) in Chapter 32), so anything that changes a compiled shape is an attribute.

def list_folder(folder=CASE57):
    """One row per file of a processed folder: its ``PREPROCESSING_PATHS`` key, writer and readers."""
    by_path = {v: k for k, v in PREPROCESSING_PATHS.items()}
    masks = {v: k for k, v in NETWORK_MASK_NAMES.items()}
    rows = []
    for path in sorted(p for p in Path(folder).rglob('*') if p.is_file()):
        rel = path.relative_to(folder).as_posix()
        key = by_path.get(rel)
        if key is None and rel.startswith(PREPROCESSING_PATHS['masks_path'] + '/'):
            key = 'masks_path' if path.name in masks else None
        parent_key = by_path.get(rel.rsplit('/', 1)[0]) if '/' in rel else None
        key = key or parent_key
        writer, readers = STAGES.get(key, ('?', '?'))
        rows.append({'file': rel, 'key': key, 'writer': writer, 'readers': readers})
    return pd.DataFrame(rows)


def hdf5_summary(path):
    """Dataset names with shapes and dtypes, and the attributes, of a static information file."""
    with h5py.File(path, 'r') as file:
        datasets = {name: (tuple(file[name].shape), str(file[name].dtype)) for name in file}
        attrs = {k: (v.item() if hasattr(v, 'item') else v) for k, v in file.attrs.items()}
    return datasets, attrs


def field_mapping(path):
    """Which ``DynamicInformation``, ``ActionSet`` or ``SolverConfig`` field each dataset and attribute maps to."""
    datasets, attrs = hdf5_summary(path)
    dyn = {f.name for f in dataclasses.fields(DynamicInformation)}
    act = {f.name for f in dataclasses.fields(ActionSet)}
    cfg = {f.name for f in dataclasses.fields(SolverConfig)}
    mapping = {}
    for name in datasets:
        if name in dyn:
            mapping[name] = f'DynamicInformation.{name}'
        elif name.startswith('action_set_') and name.removeprefix('action_set_') in act:
            mapping[name] = f'DynamicInformation.action_set.{name.removeprefix("action_set_")}'
        elif name in cfg:
            mapping[name] = f'SolverConfig.{name} (a dataset, not an attribute)'
        else:
            mapping[name] = 'built into another field at load time'
    attr_map = {k: (f'SolverConfig.{k}' if k in cfg else 'file metadata') for k in attrs}
    return mapping, attr_map

def overrides(grid_file, output_dir, runtimes=(4, 8), n_worst=(1, 2)):

def run_sweep(work_dir, **kwargs):
    """Copy the grid, run the multirun in a subprocess and return the multirun folder and the exit code.

    At ``ba1874e`` every job ends with ``ConfigKeyError: Missing key critical_va_diff_degree``: the benchmark
    builds an ``ac_validation_cfg`` with ``n_processes`` and ``k_best_topos`` only, and ``save_ac_metrics_summary``
    reads two more keys. The DC stage of every job completes before that, so the exit code is 1 and the tree holds

        check=False,

    env = dict(os.environ, PYTHONUTF8='1', PWD=str(TOOP))

def tree(root, skip=('stats', 'masks', 'tensorboard', 'sld')):
    """The directory tree of the sweep as indented lines, without the bulky leaves."""
    root = Path(root)
    lines = []
    for path in sorted(root.rglob('*')):
        rel = path.relative_to(root)
        if any(part in skip for part in rel.parts[:-1]) or rel.parts[-1] in skip:
            if rel.parts[-1] in skip and path.is_dir():
                lines.append('  ' * (len(rel.parts) - 1) + rel.parts[-1] + '/ ...')
            continue
        lines.append('  ' * (len(rel.parts) - 1) + rel.parts[-1] + ('/' if path.is_dir() else ''))
    return lines


def job_summaries(multirun_dir):
    """Per Hydra job: its overrides and the best DC fitness of the ``stats/res.json`` its DC stage wrote."""
    rows = []
    for job in sorted(p for p in Path(multirun_dir).rglob('.hydra') if p.is_dir()):
        job_dir = job.parent
        if not any(job_dir.glob('*/stats/res.json')):
            continue
        res = json.loads(next(job_dir.glob('*/stats/res.json')).read_text(encoding='utf-8'))
        job_overrides = (job / 'overrides.yaml').read_text(encoding='utf-8').split()
        rows.append(
            {
                'job': job_dir.name,
                'overrides': [o for o in job_overrides if o.startswith('ga_config')],
                'max_fitness': res['max_fitness'],
            }
        )
    return rows


def _run_in_process(argv):
    """Entry point of the subprocess: install the Windows shim, then run the Hydra app as ``__main__``.

    Hydra resolves ``config_path="configs"`` relative to the script only when the decorated function lives in
    ``__main__``; imported as a module it would look for a Python package called ``configs``.
    """
    import tensorboard_log_toop

    tensorboard_log_toop.windows_safe_log_dir()
    script = BENCHMARK / 'benchmark_toop.py'
    sys.argv = [str(script), '--multirun', *argv]
    runpy.run_path(str(script), run_name='__main__')


def main():
    """Run the sweep, print the tree and the assessment."""
    if len(sys.argv) > 1 and sys.argv[1] == '--run':
        _run_in_process(sys.argv[2:])
        return
    work_dir = Path(sys.argv[1]) if len(sys.argv) > 1 else Path(tempfile.mkdtemp(prefix='toop_sweep_'))
    multirun, code = run_sweep(work_dir)
    print(f'benchmark exit code {code}')
    print('\n'.join(tree(work_dir)))
    for row in job_summaries(multirun):
        print(row)
    logs = sorted(multirun.rglob('benchmark_toop.log'))
    if logs:
        tail = [
            line for line in logs[0].read_text(encoding='utf-8').splitlines() if 'Error' in line or 'error' in line
        ]
        print('first job log, error lines:', tail[-3:])
    report = assess(multirun, work_dir / 'aggregate_report.json')
    print('assessment report:', 'none written (no benchmark_summary.json)' if report is None else list(report)[:12])


if __name__ == '__main__':
    main()

Two small programs in the chapter's src folder show why, run in the same container from the course checkout (mounted at /course) with python shm_fill.py 200 and python ray_store_toop.py (the store size and the timing move by a few MB and hundredths of a second from run to run):

    --shm-size shm_fill.py 200 Ray object store Store moved out of /dev/shm ray.put of 200 MB
    64m return code −7 (SIGBUS) 4073 MB yes 0.46 s
    2gb return code 0 4077 MB yes 0.36 s
    4.5gb return code 0 4076 MB no 0.28 s
    • Ray does not need /dev/shm. It sizes its object store at 30 % of the memory it sees (4 GB of the VM's 13.6 GB) and, when /dev/shm is smaller, logs WARNING: The object store is using /tmp/ray instead of /dev/shm because /dev/shm has only 67108864 bytes available. This will harm performance!, suggesting --shm-size=4.38gb, and carries on with a disk-backed store. With 2 GB the warning is the same (2147483648 bytes); only from 4.5 GB does the store stay in /dev/shm. pytest captures the log of passing tests, so in the runs above the warning was never shown. With --shm-size=2gb, as the compose file sets, Ray still runs on the fallback.
    • A write past the end of /dev/shm is a signal, not an error. shm_fill.py creates a 200 MB multiprocessing.shared_memory segment, which always succeeds because tmpfs only records the length, then writes every byte in a child process. With 64 MB the kernel has no page to back the 65th megabyte and kills the writer with SIGBUS: the child's return code is −7, and the shell reports Bus error (core dumped) and exit status 135 (128 + 7). There is no Python exception, no ENOSPC, and nothing that names shared memory: the process that ran out of /dev/shm is dead before it can say so, and whatever supervises it (Ray, a ProcessPoolExecutor) reports a worker that died. With 2 GB the same fill succeeds.

    So a small /dev/shm shows up either as a performance warning nobody reads or as a crashed process with no explanation, never as "out of shared memory", because the limit is a mount size and the failing operation is an ordinary memory write. The chapter's advice still holds: pass --shm-size (or the compose file's shm_size) large enough for the heaviest user, and when a worker dies in a container, check /dev/shm and exit code 137 first. When the driver is started with uv run, Ray also packages the working directory for its workers (12.87 MiB of /app, about 30 s before the first task here); ray_store_toop.py sets RAY_ENABLE_UV_RUN_RUNTIME_ENV=0, as ToOp's CI does, to skip that.

    shm_fill.py
    """Fill a shared-memory segment larger than /dev/shm and see how the process dies (Chapter 34, Exercise 5).

Run it inside the ToOp container, once per ``--shm-size``, with the size of the segment in MB::

    python shm_fill.py 200

Creating the segment always succeeds: ``ftruncate`` on tmpfs only records a length and reserves nothing. The
pages are allocated when they are first written, and when ``/dev/shm`` has none left the kernel cannot back the
page and sends ``SIGBUS`` to the writer. There is no exception and no "out of shared memory" message: the
process is simply killed, so the fill runs in a child process and this script reports how the child ended.
Standard library only; it runs anywhere ``multiprocessing.shared_memory`` exists (on Windows the segment is a
named file mapping and the fill succeeds).
"""

import shutil
import signal
import subprocess
import sys
from multiprocessing import shared_memory
from pathlib import Path

SHM = Path('/dev/shm')  # noqa: S108 -- the shared-memory mount being measured, not a temporary file


def shm_bytes():
    """Size of the ``/dev/shm`` file system in bytes, or ``None`` where there is none (Windows, macOS)."""
    return shutil.disk_usage(SHM).total if SHM.is_dir() else None


def fill(mb):
    """Create a segment of ``mb`` MB, write a byte into every position, then release it."""
    segment = shared_memory.SharedMemory(create=True, size=mb * 2**20)
    try:
        segment.buf[:] = b'\x01' * segment.size
    finally:
        segment.close()
        segment.unlink()


def fill_in_child(mb):
    """Run :func:`fill` in a child interpreter and return its return code (negative: killed by that signal)."""
    result = subprocess.run([sys.executable, __file__, '--child', str(mb)], capture_output=True, check=False)  # noqa: S603
    return result.returncode


def describe(returncode):
    """``exit 0``, ``exit 1`` or the name of the signal that killed the child (``SIGBUS``)."""
    if returncode >= 0:
        return f'exit {returncode}'
    try:
        return signal.Signals(-returncode).name
    except ValueError:
        return f'signal {-returncode}'


def main():
    """Print the numbers quoted in the solution of Exercise 5."""
    if len(sys.argv) == 3 and sys.argv[1] == '--child':
        fill(int(sys.argv[2]))
        return
    mb = int(sys.argv[1]) if len(sys.argv) > 1 else 200
    size = shm_bytes()
    print(f'{SHM} size MB:', 'none' if size is None else round(size / 2**20))
    returncode = fill_in_child(mb)
    print(f'fill of {mb} MB: return code {returncode} ({describe(returncode)})')


if __name__ == '__main__':
    main()

    """Where Ray puts its object store, and what it says about /dev/shm (Chapter 34, Exercise 5).

Run it inside the ToOp container, once per ``--shm-size``::

    python ray_store_toop.py

Ray sizes its object store at 30 % of the memory it sees and, when ``/dev/shm`` is smaller than that, logs a
warning and puts the store in its temporary folder instead (disk-backed, slower). Nothing fails, which is why a
small ``/dev/shm`` does not show up as an error in a test run: pytest captures the warning with the rest of the
log. ``RAY_ENABLE_UV_RUN_RUNTIME_ENV=0`` (as in ToOp's CI) stops Ray from packaging the working directory for
its workers when the driver was started by ``uv run``.
"""

import logging
import os
import shutil
import time
from pathlib import Path

import numpy as np

os.environ.setdefault('RAY_ENABLE_UV_RUN_RUNTIME_ENV', '0')

import ray  # noqa: E402

SHM = Path('/dev/shm')  # noqa: S108 -- the shared-memory mount being measured, not a temporary file


class _Collect(logging.Handler):
    """Keep the messages of Ray's log records."""

    def __init__(self):
        super().__init__(logging.WARNING)
        self.messages = []

    def emit(self, record):
        self.messages.append(record.getMessage())


def object_store(put_mb=200):
    """Start a local Ray instance, put ``put_mb`` MB into its object store, read it back and shut down.

    Returns the ``/dev/shm`` size (``None`` where there is none), the object-store size Ray chose, whether Ray
    warned that the store left ``/dev/shm``, the time of the ``put`` and whether the data came back intact.
    """
    collect = _Collect()
    ray_logger = logging.getLogger('ray')
    ray_logger.addHandler(collect)
    try:
        ray.init(include_dashboard=False, ignore_reinit_error=True, log_to_driver=False)
        store_bytes = ray.available_resources()['object_store_memory']
        data = np.ones(put_mb * 2**20 // 8)
        start = time.perf_counter()
        ref = ray.put(data)
        put_seconds = time.perf_counter() - start
        intact = float(ray.get(ref).sum()) == data.size
    finally:
        ray.shutdown()
        ray_logger.removeHandler(collect)
    return {
        'shm_mb': round(shutil.disk_usage(SHM).total / 2**20) if SHM.is_dir() else None,
        'object_store_mb': round(store_bytes / 2**20),
        'fallback_warning': next((m for m in collect.messages if 'instead of /dev/shm' in m), None),
        'put_seconds': put_seconds,
        'intact': intact,
    }


def main():
    """Print the numbers quoted in the solution of Exercise 5."""
    result = object_store()
    print('ray', ray.__version__)
    print(f'{SHM} size MB:', result['shm_mb'])
    print('object store MB:', result['object_store_mb'])
    print(f'store moved out of {SHM}:', result['fallback_warning'] is not None)
    if result['fallback_warning']:
        print('  ' + result['fallback_warning'].split(' This will')[0])
    print(f'put 200 MB: {result["put_seconds"]:.2f} s, read back intact: {result["intact"]}')


if __name__ == '__main__':
    main()

    State by location: in Kafka, every command and every result (commands, results shared by both stages, heartbeat, plus the three importer topics), durable and replayable from any offset; on the shared file system, the processed grid folder written by the importer and preprocessing (Lab step 1) and the AC load-flow results (loadflow_result_fs, the StoredLoadflowReference of each AC topology); only in a worker's memory, the DC repertoire (device arrays) and each AC worker's ac_optim_topology and finished_optimizations tables, its parent_id lineage and acceptance flags. Three AC workers each build their own copy of the table from the results topic, so the picture has three private databases that never agree exactly (each has consumed up to its own offset and each ran its own mutations). A restart of AC worker 2 loses its table, the AC candidates it was evaluating and its knowledge of which optimizations finished; it recovers the DC candidates only if its consumer group re-reads results from the beginning. To restart without losing work: (1) move the store out of the process, either create_engine('sqlite:///<file on the shared file system>') or a PostgreSQL service, so ACOptimTopology survives and can be shared by the three workers, and keep scrub_db as the retention policy; (2) commit Kafka offsets only after the row is in that database, so a crash between consume and insert replays the message and the unique strategy_hash makes the replay idempotent; (3) publish the AC results, the accepted topologies and finished_optimizations as messages (they already go to results) so that a fresh worker rebuilds the lineage from the log; (4) make the AC worker's own loop restartable by writing a periodic checkpoint of the optimization it is working on (optimization_id, offsets, current candidates) next to the load-flow results. With (1) and (2) the SQLite memory box disappears from the diagram and the only non-durable state left is the DC repertoire, which the DC worker already rebuilds from OptimizationStartedResult plus the pushes it re-sends.
