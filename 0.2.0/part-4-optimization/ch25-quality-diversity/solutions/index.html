    Chapter 25 – Solutions¶

    Solutions of the Lab and the Exercises of Chapter 25. Try each task before reading its solution. The code is in the chapter's src folder: map_elites_cells.py (the cell index of the worked example), small_grid_toop.py (runs ToOp's small-grid example with any descriptors and weights; needs ToOp), repertoire.py (reads res.json: elites, heatmap, coverage, QD-score, and the cell lists of Exercises 2 and 5) and map_elites.py (MAP-Elites in NumPy on the Chapter 24 problem and the deceptive landscape of Exercise 3). The ToOp numbers were produced with ToOp ba1874e on a laptop CPU (JAX on TFRT_CPU_0), 30 s per run; the output of the lab's step 2 is committed as res_two_descriptors.json, trimmed to the fields the chapter reads, so that python repertoire.py and the notebooks work without ToOp. python map_elites.py prints the numbers of Exercises 1 and 3.

    Lab¶

    The small grid of example2_small_grid_toop.ipynb is tiny: static_information_stats.json reports 7 nodes, 9 branches, 11 N-1 cases (8 branch and 3 injection outages), 3 monitored branches, one relevant substation and 10 actions. The whole search space is ten topologies, and split_subs can only be 0 or 1; keep that in mind when reading the repertoires below.

    1. Unchanged run. res.json of the run (small_grid_toop.py OUT step1, the notebook's ga_config: split_subs with 4 cells, runtime_seconds = 30, seed 42): initial_fitness = -61.445 (initial_metrics.overload_energy_n_1 = 61.445 MW, split_subs = 0), max_fitness = -42.345, iteration = 1142 epochs, total_branch_combis = 913 608 evaluated topologies, and best_topos has one entry: action 5, one split, overload energy 42.345 MW. The first epoch alone evaluates 808 topologies, so the optimum is found at epoch 0 and the remaining 1 141 epochs change nothing. The run also writes 1 142 files res_<epoch>.json to results/test/.

      On Windows the DC stage crashes before the first epoch: optimizer/dc/main.py names the TensorBoard folder str(datetime.now()), whose colons are illegal in a Windows path (WinError 123). small_grid_toop.py patches the timestamp format on Windows; inside the container nothing is needed.

    2. Two descriptors and the plot. With me_descriptors = [split_subs: 4, switching_distance: 20] and plot = True, res.json reports three elites, all with one split:

      action split_subs switching_distance overload energy [MW] fitness
      3 1 0 57.058 −57.058
      4 1 4 57.058 −57.058
      5 1 2 42.345 −42.345

      The run completed only 125 epochs (100 008 topologies) in the same 30 s, against 1 142 without the plot: plot_repertoire saves a PNG after every epoch (126 files in results/test/plots/), and drawing costs more than the optimization on this grid. In the heatmap the three cells sit on the row split_subs = 1 in the columns 0, 2 and 4 of 20; every other cell is drawn at \(1.05 \times (-57.058) = -59.9\), the "slightly below the worst finite fitness" value of plot_repertoire, so the 77 empty cells are nearly the same color as the two cells at \(-57.058\) and only the cell at \(-42.345\) stands out. Nothing marks empty cells as empty. 3. Own heatmap, coverage, QD-score. repertoire.grid fills a (4, 20) array with NaN and writes the fitness of each elite at (split_subs, switching_distance), clipping indices like ToOp; heatmap masks the NaN cells so that they stay blank. Coverage \(= 3 / 80 = 0.0375\). With the fitness shifted by the unsplit grid, QD-score \(= (61.445 - 57.058) + (61.445 - 57.058) + (61.445 - 42.345) = 4.387 + 4.387 + 19.100 = 27.873\). The three cells are the only ones summarize reports; Exercise 4 discusses what the real archive held. 4. Weights and cells. Adding critical_branch_count_n_1 to target_metrics changes every fitness by \(-w \times\) (number of critical branches): the unsplit grid has 3 critical branches, actions 3 and 4 have 2 and action 5 has 1.

      target_metrics initial fitness fitness of actions 3, 4, 5 elites epochs
      overload energy only −61.445 −57.058, −57.058, −42.345 3, 4, 5 125 (with plots)
      + critical branches, \(w = 1\) −64.445 −59.058, −59.058, −43.345 3, 4, 5 906
      + critical branches, \(w = 10\) −91.445 −77.058, −77.058, −52.345 3, 4, 5 926
      overload energy only, cells (2, 5) −61.445 −57.058, −57.058, −42.345 3, 4, 5 895

      The set of proposed topologies does not change, and neither does their order: on a grid with ten topologies the archive is exhaustive after the first epoch, and the same action is best on both metrics, so a weight only rescales the fitness. The weights matter when two topologies trade one metric against the other (a split that removes one small overload while adding two critical branches elsewhere): a large \(w\) then prefers the fewer critical branches, and a cell elite changes. The cell change (2, 5) keeps the same three elites because the descriptor values \(\{0, 1\} \times \{0, 2, 4\}\) fit both grids; on the default (5, 45) repertoire of a real grid, fewer cells merge neighboring switching distances into one cell and the archive keeps only the best of each merged group, so the menu shrinks. To see any of this, rerun the lab on data/case57_data_powsybl (Chapter 22), which has enough substations for several splits.

    small_grid_toop.py
    """Run ToOp's small-grid example (``notebooks/example2_small_grid_toop.ipynb``) with a configurable repertoire.

Run it with ToOp's interpreter (its container or virtual environment) from this folder::

    python small_grid_toop.py OUT_ROOT NAME [--descriptors split_subs:4,switching_distance:20] [--plot]
                              [--weights overload_energy_n_1:1,critical_branch_count_n_1:10] [--seed 42]
                              [--runtime 30]

It copies the example grid ``data/grid_node_breaker/grid.xiidm`` of the ToOp checkout (``$TOOP_REPO``, default
the ``ToOp`` folder next to this repository) into ``OUT_ROOT/NAME``, runs preprocessing and the DC MAP-Elites stage
with the notebook's settings except for the overrides given, and prints where ``res.json``, the per-epoch
``res_<epoch>.json`` files and the repertoire plots are. The AC validation stage is skipped: the lab reads the DC
repertoire only.
"""

import argparse
import datetime
import json
import os
import shutil
import types
from pathlib import Path

import toop_engine_topology_optimizer.dc.main as dc_main
from omegaconf import DictConfig
from toop_engine_interfaces.messages.preprocess.preprocess_commands import PreprocessParameters
from toop_engine_topology_optimizer.benchmark.benchmark_utils import (
    PipelineConfig,
    get_paths,
    prepare_importer_parameters,
    run_pipeline,
    suppress_jax_logs,
)

TOOP_REPO = Path(os.environ.get('TOOP_REPO', Path(__file__).resolve().parents[5] / 'ToOp'))
GRID = TOOP_REPO / 'data' / 'grid_node_breaker' / 'grid.xiidm'


class _FileSafeDatetime:
    """``now()`` without colons: ``optimizer/dc/main.py`` names the TensorBoard folder ``str(datetime.now())``."""

    @staticmethod
    def now() -> str:
        return datetime.datetime.now().strftime('%Y-%m-%dT%H-%M-%S')  # noqa: DTZ005


if os.name == 'nt':
    # Windows rejects ':' in folder names, so the unpatched call fails with WinError 123 (ToOp ba1874e).
    dc_main.datetime = types.SimpleNamespace(datetime=_FileSafeDatetime)


def parse_pairs(text: str, cast=int) -> list[tuple[str, float]]:
    """``'a:1,b:20'`` into ``[('a', 1), ('b', 20)]``."""
    return [(name, cast(value)) for name, value in (item.split(':') for item in text.split(',') if item)]


def ga_config(descriptors: str, weights: str, seed: int, runtime: float, plot: bool) -> dict:
    """The notebook's ``ga_config`` with the descriptors, target weights, seed, runtime and plot flag replaced."""
    me_descriptors = [{'metric': m, 'num_cells': c} for m, c in parse_pairs(descriptors)]
    target_metrics = [[m, w] for m, w in parse_pairs(weights, float)]
    observed = ['overload_energy_n_1', 'split_subs']
    for metric in [d['metric'] for d in me_descriptors] + [m for m, _ in target_metrics]:
        if metric not in observed:
            observed.append(metric)
    return {
        'runtime_seconds': runtime,
        'random_seed': seed,
        'me_descriptors': me_descriptors,
        'target_metrics': target_metrics,
        'observed_metrics': observed,
        'n_worst_contingencies': 2,
        'plot': plot,
    }


def run(out_root: Path, name: str, config: dict) -> Path:
    """Copy the grid, run preprocessing and the DC stage; return the folder holding ``res.json``."""
    iteration = out_root / name
    iteration.mkdir(parents=True, exist_ok=True)
    shutil.copy(GRID, iteration / 'grid.xiidm')
    pipeline_cfg = PipelineConfig(root_path=out_root, iteration_name=name, file_name='grid.xiidm', grid_type='powsybl')
    iteration_path, file_path, data_folder, snapshot_dir = get_paths(pipeline_cfg)
    stats_dir = str(iteration_path / 'results' / '{task_name}')
    dc_optimization_cfg = DictConfig(
        {
            'task_name': 'test',
            'fixed_files': [str(data_folder / pipeline_cfg.static_info_relpath)],
            'double_precision': None,
            'tensorboard_dir': stats_dir,
            'stats_dir': stats_dir,
            'summary_frequency': None,
            'checkpoint_frequency': None,
            'stdout': None,
            'double_limits': None,
            'num_cuda_devices': 1,
            'omp_num_threads': 1,
            'xla_force_host_platform_device_count': None,
            'output_json': str(iteration_path / 'results' / 'output.json'),
            'lf_config': {'distributed': False},
            'ga_config': config,
        }
    )
    importer_parameters = prepare_importer_parameters(file_path, data_folder)
    importer_parameters.area_settings.cutoff_voltage = 10
    # The notebook passes enable_bb_outage and bb_outage_as_nminus1 here; Pydantic drops them silently (see the
    # chapter's warning), so they are left out.
    preprocessing_parameters = PreprocessParameters(action_set_clip=2**10)
    run_pipeline(
        pipeline_cfg=pipeline_cfg,
        importer_parameters=importer_parameters,
        preprocessing_parameters=preprocessing_parameters,
        dc_optim_config=dc_optimization_cfg,
        ac_validation_cfg=DictConfig({'n_processes': 1, 'k_best_topos': 5}),
        run_ac_validation_stage=False,
    )
    runs = sorted(snapshot_dir.glob('run_*'), key=lambda p: int(p.name.split('_')[1]))
    return runs[-1]


def summary(run_dir: Path) -> dict:
    """Headline numbers of a run: fitness before and after, epochs, evaluations and number of reported elites."""
    res = json.loads((run_dir / 'res.json').read_text(encoding='utf-8'))
    return {
        'initial_fitness': res['initial_fitness'],
        'max_fitness': res['max_fitness'],
        'epochs': res['iteration'],
        'total_branch_combis': res['total_branch_combis'],
        'reported_elites': len(res['best_topos']),
        'descriptors': [(d['metric'], d['num_cells']) for d in res['args']['ga_config']['me_descriptors']],
    }


def main() -> None:
    """Command line entry point."""
    parser = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument('out_root', type=Path)
    parser.add_argument('name')
    parser.add_argument('--descriptors', default='split_subs:4')
    parser.add_argument('--weights', default='overload_energy_n_1:1')
    parser.add_argument('--seed', type=int, default=42)
    parser.add_argument('--runtime', type=float, default=30.0)
    parser.add_argument('--plot', action='store_true')
    args = parser.parse_args()
    suppress_jax_logs()
    run_dir = run(
        args.out_root, args.name, ga_config(args.descriptors, args.weights, args.seed, args.runtime, args.plot)
    )
    print(json.dumps({'run_dir': str(run_dir), **summary(run_dir)}, indent=2))


if __name__ == '__main__':
    main()
    repertoire.py
    """Read ToOp's ``res.json``: the elites as a table, the repertoire as a heatmap, coverage and QD-score (Chapter 25).

``res.json`` is written by ``summarize`` (``optimizer/dc/genetic_functions/scoring_functions.py``). Its
``best_topos`` list holds one entry per cell elite whose fitness beats the unsplit grid, with the descriptors in
``metrics.extra_scores``. ``res_two_descriptors.json`` next to this file is the trimmed output of the lab's step 2
(``small_grid_toop.py ... --descriptors split_subs:4,switching_distance:20 --plot``, ToOp ba1874e on CPU).
"""

import json
import sys
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

HERE = Path(__file__).resolve().parent
EXAMPLE = HERE / 'res_two_descriptors.json'
KEEP_TOP = ('initial_fitness', 'initial_metrics', 'max_fitness', 'iteration', 'total_branch_combis')
KEEP_GA = ('me_descriptors', 'target_metrics', 'runtime_seconds', 'random_seed', 'plot')


def load(path: Path = EXAMPLE) -> dict:
    """The parsed ``res.json``."""
    return json.loads(Path(path).read_text(encoding='utf-8'))


def trim(res: dict) -> dict:
    """Only what the chapter reads: headline numbers, the descriptor configuration and each elite's metrics."""
    return {
        **{k: res[k] for k in KEEP_TOP},
        'args': {'ga_config': {k: res['args']['ga_config'][k] for k in KEEP_GA}},
        'best_topos': [
            {
                'actions': t['actions'],
                'disconnections': t['disconnections'],
                'metrics': {'fitness': t['metrics']['fitness'], 'extra_scores': t['metrics']['extra_scores']},
            }
            for t in res['best_topos']
        ],
    }


def descriptors(res: dict) -> list[tuple[str, int]]:
    """``(metric, num_cells)`` of each descriptor of the run."""
    return [(d['metric'], d['num_cells']) for d in res['args']['ga_config']['me_descriptors']]


def elites(res: dict) -> pd.DataFrame:
    """One row per reported elite: its descriptor values, fitness, every observed metric and the actions."""
    rows = []
    for t in res['best_topos']:
        rows.append({**t['metrics']['extra_scores'], 'fitness': t['metrics']['fitness'], 'actions': t['actions']})
    return pd.DataFrame(rows)


def grid(res: dict) -> np.ndarray:
    """Fitness per cell (rows: first descriptor, columns: second), NaN where no elite is reported; clipped indices."""
    desc = descriptors(res)
    dims = tuple(n for _, n in desc)
    table = np.full(dims, np.nan)
    for t in res['best_topos']:
        scores = t['metrics']['extra_scores']
        cell = tuple(min(int(scores[m]), n - 1) for m, n in desc)
        table[cell] = np.nanmax([table[cell], t['metrics']['fitness']])
    return table


def coverage(table: np.ndarray) -> float:
    """Reported (filled) cells over all cells."""
    return float(np.isfinite(table).mean())


def qd_score(table: np.ndarray, initial_fitness: float) -> float:
    """Sum over reported cells of the fitness gain over the unsplit grid."""
    return float(np.nansum(table - initial_fitness))


def heatmap(table: np.ndarray, desc: list[tuple[str, int]], ax=None):
    """Heatmap of the fitness per cell, empty cells left blank (unlike ToOp's plot, which fills them)."""
    ax = ax or plt.gca()
    image = ax.imshow(np.ma.masked_invalid(table), origin='lower', aspect='auto', cmap='viridis')
    ax.set_ylabel(desc[0][0])
    ax.set_xlabel(desc[1][0])
    ax.set_yticks(range(desc[0][1]))
    plt.colorbar(image, ax=ax, label='fitness')
    return image


def cells_with_value(dims: tuple[int, ...], axis: int, value: int) -> list[int]:
    """Flat indices of every cell whose descriptor ``axis`` equals ``value`` (Exercise 2)."""
    return [
        int(np.ravel_multi_index(index, dims))
        for index in np.ndindex(*dims)
        if index[axis] == min(value, dims[axis] - 1)
    ]


def clipped_cells(dims: tuple[int, ...]) -> list[int]:
    """Flat indices of the cells on the last row or column of any axis, which hold "at least" values (Exercise 2)."""
    return [
        int(np.ravel_multi_index(index, dims))
        for index in np.ndindex(*dims)
        if any(i == n - 1 for i, n in zip(index, dims, strict=True))
    ]


def main() -> None:
    """Lab step 3 on the committed run, Exercises 2 and 5; ``--trim IN OUT`` rewrites a full res.json."""
    if len(sys.argv) == 4 and sys.argv[1] == '--trim':
        Path(sys.argv[3]).write_text(json.dumps(trim(load(Path(sys.argv[2]))), indent=1), encoding='utf-8')
        return
    res = load()
    desc = descriptors(res)
    print('descriptors', desc, 'epochs', res['iteration'], 'branch combinations', res['total_branch_combis'])
    print(f'initial fitness {res["initial_fitness"]:.3f}, max fitness {res["max_fitness"]:.3f}')
    print(elites(res).to_string())
    table = grid(res)
    print(
        f'reported cells {int(np.isfinite(table).sum())} of {table.size}: coverage {coverage(table):.4f}, '
        f'QD-score {qd_score(table, res["initial_fitness"]):.3f}'
    )
    dims = (5, 45)
    two = cells_with_value(dims, 0, 2)
    print(f'cells with exactly 2 split substations: {two[0]} to {two[-1]} ({len(two)} cells)')
    clipped = clipped_cells(dims)
    print(
        f'{len(clipped)} clipped cells: last row {clipped_cells(dims)[-45:][:3]}... and last column '
        f'{[c for c in clipped if c % 45 == 44]}'
    )
    three = (5, 45, 3)
    print(f'{three}: {int(np.prod(three))} cells, {int(np.prod(three)) * 8} bytes of float64 fitness')


if __name__ == '__main__':
    main()

    Exercise 1¶

    map_elites.py reuses the fitness and the genotype of Chapter 24 (its src folder is put on the import path). The descriptors are the number of switched lines (0 to 3, 4 cells) and the maximum N-0 loading after switching, binned at 90, 100, 110 and 130 % (5 cells); the unswitched grid has 108.3 %, so it sits in cell \((0, 2)\). The archive keeps the best genome per cell; each iteration mutates a random elite (crossed with another elite half the time) and inserts the child if its cell is empty or worse. Same budget as the GA, 1 152 evaluations. Seed 0:

    evaluations 32 100 300 600 1 152
    coverage 0.20 0.50 0.65 0.65 0.70
    QD-score [MW] −216.5 −38.2 258.8 423.0 399.6
    best \(E\) [MW] 72.350 14.391 14.391 14.391 14.391

    The QD-score starts negative because the first random cells are worse than the unswitched grid (a cell adds \(f_{\text{cell}} - f_{\emptyset}\), negative for a bad cell), and it can fall when a new cell is filled with a bad topology (600 → 1 152), which is why ToOp's summarize drops cells that do not beat the unsplit grid. The final archive, overload energy per cell (rows: lines switched, columns: loading bins):

    lines \ N-0 loading < 90 % 90–100 100–110 110–130 ≥ 130
    0 – – 145.4 – –
    1 – – 69.4 188.9 311.1
    2 27.3 168.8 63.5 109.8 217.7
    3 14.4 22.9 59.9 68.8 167.2

    Over ten seeds the best cell is always \(14.391\) MW (10 of 10 seeds, against 9 of 10 for the GA of Chapter 24 with the same budget), coverage ends between 0.65 and 0.70 and the QD-score between 347.1 and 439.3 MW. Six cells are never filled by any seed: the four cells \((0, \cdot)\) other than \((0, 2)\) cannot exist (no lines switched is one grid, with one loading), and \((1, 0)\), \((1, 1)\) do not exist either: no single switch brings the maximum N-0 loading below 100 %. The archive is also a readable answer in itself: the row "3 lines" shows the operator what the best topology is for each level of remaining N-0 stress, the menu of solutions that ToOp's repertoire gives for split_subs and switching_distance.

    map_elites.py
    """MAP-Elites in NumPy for the line-switching problem of Chapter 24, and a deceptive 1-D landscape (Chapter 25).

The archive is a grid with two integer descriptors, the number of switched lines (0 to 3) and the maximum N-0
loading after switching binned into 5 cells; each cell keeps the best genome that landed in it. Coverage is the
fraction of filled cells and the QD-score the sum over filled cells of (fitness - fitness of the unswitched grid),
so that a cell only adds to the score when it beats doing nothing.

The fitness and the genotype come from Chapter 24's ``src`` folder, put on the import path below.
"""

import sys
from dataclasses import dataclass, field
from pathlib import Path

import numpy as np

sys.path.insert(0, str(Path(__file__).resolve().parents[2] / 'ch24-evolutionary-algorithms' / 'src'))

from genome_mutation import mutate  # noqa: E402
from line_switching import Case, kept_branches, load_case30, n1_flows  # noqa: E402
from switching_ga import BUDGET, K_MAX, crossover, random_genome  # noqa: E402

LOADING_EDGES = (90.0, 100.0, 110.0, 130.0)  # N-0 loading bins: <90, 90-100, 100-110, 110-130, >=130 %
CELLS = (K_MAX + 1, len(LOADING_EDGES) + 1)


def evaluate(case: Case, genome: np.ndarray) -> tuple[float, tuple[int, int] | None]:
    """Fitness and descriptor cell (lines switched, N-0 loading bin) of a genome; the cell is None if islanded."""
    lines = genome[genome < case.n_branch]
    result = n1_flows(case, lines)
    if result is None:
        return -np.inf, None
    f0, f1, bridge = result
    keep = kept_branches(case, lines)
    over = np.maximum(0.0, np.abs(f1) - case.limit[keep][:, None])
    over[:, bridge] = 0.0
    loading = float((100.0 * np.abs(f0) / case.limit[keep]).max())
    return -float(over.sum()), (len(lines), int(np.searchsorted(LOADING_EDGES, loading, side='right')))


@dataclass
class Archive:
    """The grid archive and the history of coverage, QD-score and best fitness against evaluations."""

    cells: tuple[int, int]
    baseline: float
    fitness: np.ndarray = field(init=False)
    genomes: dict[tuple[int, int], np.ndarray] = field(default_factory=dict)
    history: list[tuple[int, float, float, float]] = field(default_factory=list)
    n_evaluations: int = 0

    def __post_init__(self):
        """Start with every cell empty."""
        self.fitness = np.full(self.cells, -np.inf)

    def insert(self, genome: np.ndarray, value: float, cell: tuple[int, int] | None) -> None:
        """Count the evaluation and keep the genome if its cell is empty or held a worse one."""
        self.n_evaluations += 1
        if cell is not None and value > self.fitness[cell]:
            self.fitness[cell] = value
            self.genomes[cell] = genome.copy()
        self.history.append((self.n_evaluations, self.coverage, self.qd_score, self.best))

    @property
    def filled(self) -> np.ndarray:
        """Boolean mask of the filled cells."""
        return np.isfinite(self.fitness)

    @property
    def coverage(self) -> float:
        """Filled cells over all cells."""
        return float(self.filled.mean())

    @property
    def qd_score(self) -> float:
        """Sum over filled cells of the fitness gain over the unswitched grid (negative for cells worse than it)."""
        return float((self.fitness[self.filled] - self.baseline).sum())

    @property
    def best(self) -> float:
        """Best fitness in the archive."""
        return float(self.fitness.max()) if self.filled.any() else -np.inf

    def table(self) -> np.ndarray:
        """Overload energy per cell (rows: lines switched, columns: loading bin), NaN where empty."""
        return np.where(self.filled, -self.fitness, np.nan)


def map_elites(case: Case, seed: int, budget: int = BUDGET, batch: int = 32, p_crossover: float = 0.5) -> Archive:
    """Fill an archive with ``budget`` evaluations: random genomes first, then mutated (and crossed) elites."""
    rng = np.random.default_rng(seed)
    n = case.n_branch
    archive = Archive(CELLS, baseline=evaluate(case, np.full(K_MAX, n))[0])
    for _ in range(batch):
        g = random_genome(K_MAX, n, rng)
        archive.insert(g, *evaluate(case, g))
    while archive.n_evaluations < budget:
        elites = list(archive.genomes.values())
        parent = elites[rng.integers(len(elites))]
        if rng.random() < p_crossover:
            parent = crossover(parent, elites[rng.integers(len(elites))], n, rng)
        child = mutate(parent, n, rng)
        archive.insert(child, *evaluate(case, child))
    return archive


N_POINTS = 100  # the 1-D genotype is an integer 0 <= x < 100


def deceptive_fitness(x: np.ndarray) -> np.ndarray:
    """A wide hill of height 10 at x = 20, a flat valley, and a narrow peak of height 20 at x = 85."""
    x = np.asarray(x, dtype=float)
    hill = 10.0 * np.exp(-(((x - 20.0) / 15.0) ** 2))
    peak = 20.0 * np.exp(-(((x - 85.0) / 2.0) ** 2))
    return hill + peak


STEP = 10  # a mutation moves x by up to STEP, the width of one archive cell


def step(x: int, rng: np.random.Generator, step_size: int = STEP) -> int:
    """Mutation: move by a nonzero integer in [-step_size, step_size], clipped to the domain."""
    delta = int(rng.integers(1, step_size + 1)) * int(rng.choice([-1, 1]))
    return int(np.clip(x + delta, 0, N_POINTS - 1))


def ga_1d(seed: int, budget: int = 2000, pop_size: int = 20, n_elite: int = 2, step_size: int = STEP) -> int:
    """Elitist GA with tournament selection; returns the best x found."""
    rng = np.random.default_rng(seed)
    population = rng.integers(0, 60, size=pop_size)  # start on the left, where the hill is
    values = deceptive_fitness(population)
    evaluations = pop_size
    while evaluations < budget:
        order = np.argsort(values)[::-1]
        children = []
        for _ in range(pop_size - n_elite):
            a, b = rng.choice(pop_size, size=2, replace=False)
            parent = population[a] if values[a] >= values[b] else population[b]
            children.append(step(int(parent), rng, step_size))
        population = np.concatenate([population[order[:n_elite]], children])
        values = deceptive_fitness(population)
        evaluations += pop_size - n_elite
    return int(population[np.argmax(values)])


def map_elites_1d(seed: int, budget: int = 2000, n_cells: int = 10, step_size: int = STEP) -> int:
    """MAP-Elites with the descriptor "which tenth of the domain x lies in"; returns the best x found."""
    rng = np.random.default_rng(seed)
    archive = {}
    for x in rng.integers(0, 60, size=20):
        archive.setdefault(int(x) * n_cells // N_POINTS, int(x))
    evaluations = 20
    while evaluations < budget:
        parent = list(archive.values())[rng.integers(len(archive))]
        child = step(parent, rng, step_size)
        cell = child * n_cells // N_POINTS
        if cell not in archive or deceptive_fitness(child) > deceptive_fitness(archive[cell]):
            archive[cell] = child
        evaluations += 1
    return max(archive.values(), key=lambda x: float(deceptive_fitness(x)))

    Exercise 2¶

    With dims = (5, 45) the flat index is \(i \cdot 45 + j\) for split_subs \(= i\) and switching_distance \(= j\). Exactly 2 split substations means row \(i = 2\): cells \(90\) to \(134\), 45 cells (repertoire.cells_with_value). Because ravel_multi_index(..., mode='clip') clips each descriptor to its last index, the last row holds every topology with 4 or more splits (cells 180 to 224) and the last column every topology with 44 or more switching operations (cells 44, 89, 134, 179, 224): \(45 + 5 - 1 = 49\) cells whose descriptor values are lower bounds, not exact values, cell 224 on both axes. The worked example's first topology, 1 split and 60 operations, lands in cell 89 together with any one-split topology with 44 or more operations; the second, 7 splits and 3 operations, in cell 183 with the 4-, 5- and 6-split topologies with 3 operations.

    Exercise 3¶

    deceptive_fitness on the integers \(0 \le x < 100\): a wide hill \(10\,e^{-((x-20)/15)^2}\) and a narrow peak \(20\,e^{-((x-85)/2)^2}\), with a valley between them where the fitness is below \(0.01\) (at \(x = 20, 50, 60, 70, 80, 83, 85\) it is \(10\), \(0.183\), \(0.0082\), \(0.0001\), \(0.0386\), \(7.36\), \(20\)). Both algorithms start with 20 points drawn from \(0 \le x < 60\), mutate by a nonzero step of at most 10, and spend 2 000 evaluations.

    • The elitist GA (tournament of two, two elites) ends at \(x = 20\) in 20 of 20 seeds. Any child in the valley has a fitness below 0.2, loses every tournament against the hill and is never a parent; a child would have to jump from the hill (\(x \le 30\)) to \(x \ge 83\) in one step to be selected, and the mutation cannot.
    • MAP-Elites with the descriptor "which tenth of the domain \(x\) is in" (10 cells) ends at \(x = 85\) in 20 of 20 seeds. A child at \(x = 62\) has a terrible fitness but an empty cell, so it is kept; it becomes a parent as often as the hill's elite, its children fill the next cell, and after a few hops a child lands on the slope of the peak. The valley elites are stepping stones: they are not good solutions, they are the only route to one, and only an algorithm that rewards being different (occupying a new cell) rather than being better keeps them.

    A detail worth knowing: with steps of at most 2 instead of 10, MAP-Elites also fails (0 of 20). The valley slopes down towards the peak until \(x \approx 80\), so the elite of each valley cell is the point nearest to the hill, and children of that elite that move right are worse and never replace it; a cell is only crossed when one mutation can jump from the elite to the next cell. Descriptors give the archive its memory, but the variation operator still has to reach the next stepping stone.

    Exercise 4¶

    summarize_repo calls filter_repo(repertoire, initial_fitness) before converting cells to topologies, so best_topos holds only the cell elites with a fitness strictly better than the unsplit grid. A coverage computed from res.json is therefore a lower bound on the archive's coverage: in step 3 it counts 3 of 80 cells, but every topology ToOp evaluated has a cell, including the unsplit grid itself (cell \((0, 0)\), dropped because it does not beat itself) and the one-split actions that worsen the overload energy. On the small grid the filled cells are at least \((0, 0)\) plus the cells of the nine split actions, whichever beat the unsplit grid or not. The true coverage is not in res.json. Three ways to get it: (a) in the process that ran the optimizer, read repertoire.fitnesses (the flat array of one fitness per cell, \(-\infty\) for empty cells) and count the finite entries; this is what plot_repertoire draws, so (b) the saved repertoire_<epoch>.png files show the true filled cells, with the empty ones at \(1.05 \times\) the worst finite fitness; or (c) re-evaluate every topology of the search space with the DC solver, compute its descriptors and count the distinct cells, which is feasible here (ten topologies) and is the brute force of Chapter 24. Whatever the route, report which definition you used: "cells that beat the unsplit grid" and "cells ever filled" differ by exactly the elites that filter_repo drops, and on a grid where few splits help the two numbers are far apart.

    Exercise 5¶

    Three descriptors with 5, 45 and 3 cells give \(5 \times 45 \times 3 = 675\) cells (np.prod), three times the default 225. The fitness array is one float64 per cell, \(675 \times 8 = 5\,400\) bytes; with cell_depth \(= d\) the repertoire keeps \(d\) topologies per cell, \(5\,400\,d\) bytes of fitness, and the genotypes (a few integers per topology) dominate the memory anyway. The archive is not the problem; the picture is. plot_repertoire (optimizer/dc/repertoire/plotting.py) reshapes the flat array to n_cells_per_dim and dispatches on its length: a bar chart for one descriptor, a seaborn heatmap for two, and for anything else raise ValueError("Only 1D and 2D plots are supported"), with a TODO for 3-D heatmaps. The test test_plot_repertoire_refuses_three_descriptors in test_small_grid_toop_toop.py triggers that error with a \((5, 45, 3)\) array. To look at a three-descriptor repertoire, slice it: one heatmap per value of disconnected_branches (three \(5 \times 45\) panels), which is also how an operator would read it, one menu per number of disconnected branches.
